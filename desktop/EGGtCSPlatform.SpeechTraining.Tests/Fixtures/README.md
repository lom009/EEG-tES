# 通用 API 迁移基线

`GenericApiBaseline.json` 是第二阶段（移除训练兼容层）迁移前捕获的只读期望值。
测试中的 `PipelineBaselineCases` 只生成当前实现的实际值，不生成或更新此文件。

基线捕获时包络低通滤波默认开启。现在业务默认关闭，因此旧基线与 SciPy 滤波参考测试显式设置 `EnableFilter: true`；默认关闭路径及开关切换的缓存、执行快照另行验证，不修改冻结数据或容差。

- 64 组：11025/16000 Hz、单/双声道、原速、固定/自适应语速、加噪、四种声码器、干净支路声码器、有/无噪声 RIR 及 RIR 后声码器。
- 每个字段先保持 .NET JSON 数值表示、递归排序对象属性，再保存 SHA256；数组次序保持不变。
- 播放和参考音频比较 PCM 字节 SHA256；全量包络比较 double 样本字节 SHA256。另比较显示分桶、刺激预览、时间对齐、语速、混音和 RIR 数值。
- 旧来源枚举/步骤列表不属于新 API；RIR 设置从平铺记录改为通用声学设置与业务噪声选择的组合，因此不比较这两种对象形状。RIR 哈希、时序、长度、校准及噪声数值仍逐字段比较。
- 不使用新实现重新生成期望值，也不放宽 MATLAB/SciPy 参考容差。

捕获先在旧实现仍存在时完成；补充全量包络时使用了同一次构建保留的旧程序集副本，未链接迁移后的项目。用于捕获的程序集 SHA256：

|---|---|

| Audio.Dsp | `39773D7D2580706D3331DBEFCD47370DDE76A5CD8E0BB4F7F95DE5049807BFAF` |

MATLAB 声码器、研究 RIR 和 SciPy 包络参考夹具在 `EGGtCSPlatform.Audio.Dsp.Tests/Fixtures` 中。训练测试保留包络夹具，用于验证刺激预览的后续计算。
