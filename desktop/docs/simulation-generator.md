# 实验数据生成器

登录主程序后，在主窗口按 **Ctrl+Shift+G** 打开独立窗口。再次按快捷键会激活已有窗口。无需连接设备。

1. 在“生成与参数”中选择范式、例数、时间、随机种子、采样率、阶段时长和 EEG 参数。
2. 在“靶点与电极”中双击表格单元格，编辑电极、物理通道和电流。相同靶点编号属于一组，每组必须有一个固定通道，回流通道电流之和等于固定通道电流。支持双通道、HD 及当前配置允许的多靶点。
3. 点击“校验配置”查看预计例数、时长和采样数量，再点击“生成并保存到历史记录”。
4. 在历史记录中按实验编号、被试、范式、日期或状态查找。展开运行记录，进入结果页即可回放。

记录间隔默认固定为60分钟。勾选“使用随机记录间隔”后，可指定最小和最大间隔（分钟，支持小数）；每条记录的开始时间在上一条开始时间上累加一次范围内的均匀随机间隔。首条使用指定开始时间，相同随机种子与范围可复现时间安排。上下限相等时等同固定间隔；允许零间隔，间隔不包含额外的实验持续时间。

“包络-tACS：32例随机对照”预设生成32名不同被试，每人一次，固定16例包络刺激、16例假刺激。随机种子决定分配和 EEG；重复生成使用新批次、被试和实验编号，避免覆盖原记录。同一参数和种子产生相同分配与样本，不预设疗效或显著差异。

包络参数包含载波频率、调制频率、深度和时延。结果页中，包络-tACS 与其他范式采用相同的展示布局，通过范式名称区分；回放显示 EEG 和阶段时间轴，不显示刺激电流或包络曲线。包络不受硬件支持状态影响，也不能通过复制配置、重新运行或配置导出转成设备刺激。

每个周期依次包含采集、消隐、刺激、恢复，最后附加一次采集。手动模式固定一个周期；自动模式为配置的有限周期数。EEG 只出现在采集阶段，其余阶段保留时间间隔。记录时间与实际生成时间分别存储。采集映射保存在记录中，不会修改系统设备映射。

生成按数据块写入；每例原始文件完成并校验后，才提交完整数据库记录。取消或当前例失败会保留已完成例，清理当前未完成例。关闭生成中的窗口会请求取消，待清理结束后可以关闭。应用正常退出时也会等待生成服务取消。单批最多1000例、单例总时长最多24小时，长时多通道记录需要相应磁盘空间。

历史列表不区分来源，所有记录共用查询、分页、回放与导出流程。CSV 使用统一的时间、阶段和 EEG 通道列，EDF 直接使用实验编号；不额外导出元数据文件。普通范式可导出 .expp 配置；包络记录请仅导出 EDF/CSV，当前设备配置格式不支持包络。

新记录只保存普通实验配置、阶段事件和 EEG 原始样本，不写入来源参数。已有数据库参数列保留兼容，查询、回放和导出不依赖该字段。新记录默认使用 SUB 被试前缀和 EXP- 实验编号。

## 验证

当前 EEG 算法为 `signal-v3`，实时模拟设备与批量生成器共用 DeviceSdk 中的生成器，默认表现为带少量采集干扰的静息脑电。背景采用多个倍频程的随机正交调制成分，形成近似 1/f 频谱趋势；主节律包含个体频率差异、随机的缓慢相位变化和幅度起伏，并叠加较弱的 delta、theta、beta 和低 gamma 成分。各通道混合共同成分与独立成分，以形成部分相关性。物理通道编号决定通道特征，改变通道选择或排列不改变已有通道的样本。

噪声幅度单独控制测量噪声、轻微基线漂移、微弱 50 Hz 干扰，以及随机时刻、幅度和持续时间的眨眼与肌电短暂干扰。眨眼在通道间共享事件时间，肌电以通道独立的高频随机成分为主；事件边缘平滑，跨生成块保留完整事件。噪声设为零后仍保留神经活动的随机背景。高频成分预留调制边带空间，并在采样率的 30%–45% 区间平滑衰减，超过该范围的振荡分量不参与生成；这是工程上的带宽约束，随机包络仍有微弱频谱尾部，不是理想砖墙滤波器。

EEG 幅度是整体活动的尺度参数，不是固定峰值或严格 RMS。批量数据基于实验绝对采样时间，分块、随机读取及采集阶段之间不会重置波形；相同种子与参数可复现结果。组别不参与信号计算，不预设刺激前后的疗效差异。实现是现象学近似，未使用头部解剖前向模型，也未针对具体设备、被试或实测数据完成校准。频谱和通道相关性测试验证算法特征，不代表已验证与实测分布一致。

实时模拟固定使用种子 42、被试标识 1，活动幅度 25 μV、噪声幅度 5 μV、主节律 10 Hz。每次采集仍沿用原有的阶段内时间起点，帧内样本通过绝对整数序号生成；批量生成沿用实验时间轴，采集间隔不写入 EEG。新批量记录默认使用 `signal-v3`；显式指定 `signal-v1`、`synthetic-v1` 或 `signal-v2` 时保留原算法结果，已保存记录不重新生成。生成器没有随时长增长的状态或历史缓存。

设计依据：[周期与非周期频谱成分研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC8106550/)；[MNE 信号与噪声建模示例](https://mne.tools/stable/auto_examples/simulation/simulate_raw_data.html)。具体权重、事件频率和时长为工程默认值。
