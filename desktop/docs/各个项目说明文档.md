说明：当前项目名称 `EGGtCSPlatform` 中的 `EGG` 为笔误，实际应为表示脑电的 `EEG`。目前暂保留原名称，不进行统一更名，不影响系统功能及使用。



当前[解决方案](D:/work_project/EGGtCSPlatform/EGGtCSPlatform.sln)包含 **13 个项目**，分为应用、设备通信、测试与示例。下表省略统一前缀 `EGGtCSPlatform.`。

| 项目                     | 主要作用                                                     |
| ------------------------ | ------------------------------------------------------------ |
| **EGGtCSPlatform**       | 主应用的界面和业务逻辑：设备连接、刺激参数配置、实验运行、EEG 波形显示、历史记录及数据存储等。使用 Avalonia。 |
| **Desktop**              | 桌面程序启动入口，负责启动主应用。平时运行、调试软件通常选择这个项目。 |
| **WindowsSetup**         | Windows 安装引导程序，提供安装目录选择，并调用内嵌的 Velopack 安装包。 |
| **Communication.Core**   | 通信基础层，定义传输、协议、设备会话等通用抽象，处理通信策略、异常及日志。 |
| **Communication.Udp**    | UDP 通信实现，包括数据收发、广播发现，以及多个设备共享 UDP 端口。 |
| **DeviceSdk**            | 面向上层的设备操作接口，统一设备命令、能力、事件和设备管理，同时提供模拟设备。 |
| **Protocol.EggtCs.Gen1** | 第一代 EGGtCS 设备协议实现，负责命令定义、帧编解码、校验、响应匹配、心跳及 EEG 数据解析。 |
| **DeviceRuntime**        | 将 SDK、传输和协议组织成可使用的设备运行环境，统一设备发现、连接、重连及真实／模拟设备配置。 |
| **Communication.Sample** | 独立控制台示例，演示脱离界面使用设备通信功能，默认使用模拟设备，也支持真实设备。 |
| **Tests**                | 主应用相关自动化测试，覆盖实验业务、ViewModel、数据持久化、波形处理和部分通信逻辑。 |
| **Communication.Tests**  | 通信专项测试，覆盖 UDP、协议命令、数据帧、事件及通信运行行为。 |
| **DeviceRuntime.Tests**  | 设备运行时专项测试，重点验证协议模块接入、协议版本及命令扩展兼容性。 |
| **VisualTests**          | 界面视觉验收程序，自动操作真实页面、检查交互并生成截图。     |

阅读代码可以从 **Desktop → EGGtCSPlatform** 入手；研究设备接入则重点看 **DeviceRuntime、DeviceSdk、Protocol.EggtCs.Gen1 和 Communication 两个项目**。
