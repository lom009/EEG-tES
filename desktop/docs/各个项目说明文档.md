# 各个项目说明

核对日期：2026-10-20。以当前工作区的解决方案、项目引用和代码实现为准，包含尚未提交的音频模块拆分。

说明：当前项目名称 `EGGtCSPlatform` 中的 `EGG` 为笔误，实际应为表示脑电的 `EEG`。目前暂保留原名称，不进行统一更名，不影响系统功能及使用。



当前[解决方案](../EGGtCSPlatform.sln)包含 **21 个 C# 项目**（不计 `Solution Items` 解决方案文件夹），分为应用、设备通信、音频与言语训练、测试和示例。除 `WindowsSetup` 使用 `net10.0-windows` 外，其他项目均使用 `net10.0`。下表省略统一前缀 `EGGtCSPlatform.`。

## 应用与设备通信（13 个）

| 项目                     | 主要作用                                                     |
| ------------------------ | ------------------------------------------------------------ |
| **EGGtCSPlatform**       | 主应用的界面和业务逻辑：设备连接、刺激参数配置、实验运行、EEG 波形显示、历史记录及数据存储等。使用 Avalonia。 |
| **Desktop**              | 桌面程序启动入口，负责启动主应用。平时运行、调试软件通常选择这个项目。 |
| **WindowsSetup**         | Windows 安装引导程序，提供安装目录选择，并调用内嵌的 Velopack 安装包。 |
| **Communication.Core**   | 通信基础层，定义传输、协议、设备会话等通用抽象，处理通信策略、异常及日志。 |
| **Communication.Udp**    | UDP 通信实现，包括数据收发、广播发现，以及多个设备共享 UDP 端口。 |
| **DeviceSdk**            | 面向上层的设备操作接口，统一设备命令、能力、事件和设备管理，同时提供模拟设备。 |
| **Protocol.EggtCs.Gen1** | 第一代 EGGtCS 设备协议实现，负责命令定义、帧编解码、校验、响应匹配、心跳及 EEG 数据解析。 |
| **DeviceRuntime**        | 将 SDK、传输和协议组织成可使用的设备运行环境，统一设备发现、连接、重连及真实／模拟设备配置。 |
| **Communication.Sample** | 独立控制台示例，演示脱离界面使用设备通信功能，默认使用模拟设备，也支持真实设备。 |
| **Tests**                | 主应用相关自动化测试，覆盖实验业务、ViewModel、数据持久化、波形处理和部分通信逻辑。 |
| **Communication.Tests**  | 通信专项测试，覆盖 UDP、协议命令、数据帧、事件及通信运行行为。 |
| **DeviceRuntime.Tests**  | 设备运行时专项测试，重点验证协议模块接入、协议版本及命令扩展兼容性。 |
| **VisualTests**          | 界面视觉验收程序，自动操作真实页面、检查交互并生成截图。     |

## 音频与言语训练（8 个）

| 项目 | 主要作用 |
| --- | --- |
| **Audio.Core** | 无第三方包的通用音频基础层：只读 PCM16／浮点／复数缓冲区、流水线节点与端口、输出路由、执行器、中间件、时间关系及 `IAudioPlayer`。 |
| **Audio.Dsp** | 仅引用 Core；提供 PCM16 WAV 读取、SOLAFS 变速、重采样、双输入加噪、RIR、声码器和可组合包络算法，不依赖训练资源或 UI。 |
| **Audio.Sdl** | 仅引用 Core，并使用 SDL3-CS 及原生包；实现 `SdlAudioPlayer`，负责默认设备播放、进度、取消和输出流音量。 |
| **SpeechTraining** | 引用 Core、Dsp；提供语料与句表、五种训练模式、内置音频图预设、资源解析、自适应规则、逐字评分、显示数据及内存结果。语料和噪声资源由此项目复制到输出目录。 |
| **Audio.Sample** | 仅直接引用 Dsp 的控制台示例，演示自定义节点、播放／包络路由、噪声预处理和包络子节点；不播放声音，无需训练资源或原生库。 |
| **Audio.Core.Tests** | 缓冲区、源节点、信号类型、图校验、路由、时间域和执行器测试。 |
| **Audio.Dsp.Tests** | DSP 路由、包络、RIR、声码器、双输入噪声及 MATLAB／SciPy 固定参考数据测试，不依赖训练程序集。 |
| **SpeechTraining.Tests** | 训练预设、请求与快照、会话、评分、自适应规则、资源及迁移基线测试；另含默认不运行的音频设备测试，不依赖 Avalonia。 |

## 依赖与阅读入口

音频依赖方向为 `Audio.Dsp → Audio.Core`、`Audio.Sdl → Audio.Core`、`SpeechTraining → Audio.Core + Audio.Dsp`。主应用引用 `SpeechTraining` 和 `Audio.Sdl`，在 `Bootstrap/Bootstrapper.cs` 中装配训练会话与播放器。训练核心本身不引用 SDL、Avalonia 或设备 SDK。

设备侧由 `DeviceRuntime` 引用 `Communication.Core`、`Communication.Udp` 和 `DeviceSdk`；具体协议项目 `Protocol.EggtCs.Gen1` 引用 Core 与 SDK，通过协议模块接入运行时。主应用和通信示例负责选择协议与真实／模拟运行方式。

文档按“如何调用”与“内部如何实现”分工：

| 模块 | 接入、API 和示例 | 原理和内部流程 |
| --- | --- | --- |
| 通用音频 | [音频处理模块复用指南](音频处理模块复用指南.md) | [音频处理模块原理与流程](音频处理模块原理与流程.md) |
| 言语训练 | [言语训练模块复用指南](言语训练模块复用指南.md) | [言语训练模块原理与流程](言语训练模块原理与流程.md) |

阅读代码可以从 **Desktop → EGGtCSPlatform** 入手；研究设备接入则重点看 **DeviceRuntime、DeviceSdk、Protocol.EggtCs.Gen1 和 Communication 两个项目**。

复用通用音频从 `Audio.Sample/Program.cs` 入手；复用完整训练流程从 `SpeechTraining/Sessions/SpeechTrainingSession.cs` 入手，继续阅读 `Processing/TrainingAudioPreparationService.cs` 和 `Processing/Presets/TrainingAudioPreset.cs`。目录分组不代表命名空间拆分：训练公开类型仍位于 `EGGtCSPlatform.SpeechTraining`，通用音频类型按 Core／Dsp 子目录划分命名空间。
