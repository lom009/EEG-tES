# 言语训练模块复用指南

面向接入言语训练的调用方：介绍资源部署、会话与模式 API、评分、结果和复用注意事项。

核对日期：2026-11-10，以当前工作区实现为准。

需要联合设备输出时，开始训练前调用 `AttachStimulation(ISpeechStimulationOutput, EnvelopePlaybackSettings)`。接口不依赖设备 SDK，宿主负责配置响应、启动响应、刺激完成等待和停止确认。启用后，`StartAsync`、`ReplayAsync`、`SaveNextAsync` 返回的任务包含本句完整输出生命周期；播放期间通过 `Changed` 更新界面，不要在 UI 线程同步等待。播放中仍可评分，切句和重播等待设备停止确认。使用 `StopAsync` / `EndAsync` 收尾，等待完成后再 Dispose；同步 Stop / Dispose 仅取消本地播放并触发已有异步流程的清理。

仅训练开始前且 `CanAdjustStimulation` 为真时，可调用 `ConfigureStimulationAsync` 修改包络设置；训练开始后整轮锁定，句间、停止或播放失败不会解锁。`IsPreparingStimulus` 期间禁止启动；`StimulusPlan` 保存实际字节和由字节反算的 mA 预览。默认不绑定输出时保留原有纯音频行为。桌面设备接入与故障恢复详见[训练原理](言语训练模块原理与流程.md#桌面包络刺激输出)。

相关文档：[音频处理模块复用指南](音频处理模块复用指南.md) · [音频处理模块原理与流程](音频处理模块原理与流程.md) · [言语训练模块原理与流程](言语训练模块原理与流程.md)。

## 依赖与资源部署

### 引用项目

也可使用 `scripts/Pack-NuGet.ps1` 生成本地包，按 [NuGet 打包与接入](NuGet打包与接入.md) 安装 SpeechTraining 和可选的 Audio.Sdl。训练包包含内置语料和噪声，并在直接/间接包引用时复制到构建与发布目录；不包含桌面的设备输出适配器。

| 项目 | 复用职责 |
| --- | --- |
| `EGGtCSPlatform.SpeechTraining` | 语料、句表、会话、训练设置、准备服务、评分、显示数据及内存结果 |
| `EGGtCSPlatform.Audio.Core`／`Audio.Dsp` | 由 SpeechTraining 传递引用；提供音频类型和算法参数 |
| `EGGtCSPlatform.Audio.Sdl` | 可选的系统默认设备播放器；自定义 `IAudioPlayer` 时不必引用 |

使用 .NET 10，无需引用 Avalonia、主应用或设备 SDK。训练公开类型均在 `EGGtCSPlatform.SpeechTraining` 命名空间；通用音频类型使用各自子命名空间，仓库的 `AudioUsings.cs` 不会传递到外部项目。

从仓库根目录创建控制台项目：

```powershell
dotnet new console --framework net10.0 --output artifacts/SpeechTrainingGuide
dotnet add artifacts/SpeechTrainingGuide/SpeechTrainingGuide.csproj reference EGGtCSPlatform.SpeechTraining/EGGtCSPlatform.SpeechTraining.csproj
dotnet add artifacts/SpeechTrainingGuide/SpeechTrainingGuide.csproj reference EGGtCSPlatform.Audio.Sdl/EGGtCSPlatform.Audio.Sdl.csproj
```

项目引用会复制 `SpeechCorpora`、`SpeechNoises` 到构建和发布目录。手工部署需保留 SpeechTraining、Audio.Core、Audio.Dsp、Audio.Sdl 四个程序集、SDL3-CS 托管依赖、对应平台 SDL3 原生库及两个资源目录。只使用准备服务或替代播放器时无需 SDL。

### 语料与噪声目录

```text
应用输出目录/
  SpeechCorpora/
    MSP/
      corpus.json
      sentences.txt
      1.wav … 100.wav
    MHINT/       （240 句）
    MHINT-P/     （40 句练习语料）
  SpeechNoises/
    SSN-MSP.wav
    Babble-MSP.wav
    SSN-MHINT.wav
    Babble-MHINT.wav
```

`FileSpeechCorpusProvider()` 默认读取 `AppContext.BaseDirectory/SpeechCorpora`；`FileSpeechCorpusProvider(root)` 的 root 应直接包含各语料库目录。`FileSpeechNoiseProvider(root)` 则直接指向含噪声 WAV 的目录。

- `sentences.txt` 为 UTF-8，允许 BOM；每个非空行是一句正文，不加编号。第 N 个非空行对应 `N.wav`，数字不补零，小写扩展名准确匹配。
- WAV 支持 16 位 PCM、8–192 kHz、单／双声道。解码或资源错误会报告，不替换为其他录音。
- 新句子追加到正文末尾并添加对应 WAV；插入、重排已有行会改变资源对应关系。新语料库建立同样的完整目录即可，支持中文目录名。
- 空语料、损坏文本、缺失／多余 WAV、错误命名、仅大小写不同的重复目录会报错；目录及文件链接不作为语料加载。
- 内置显示顺序为 MSP、MHINT、MHINT-P，其余自然排序。源码语料维护在训练项目的 `Resources`，噪声维护在 `NoiseResources`。
- 默认每表 20 句，服务接受任意正整数，最后一表保留余数。句表 ID 如 `"01"`；句子稳定 ID 如 `"MSP/091"` 不随分组变化。

### corpus.json

完整示例（MSP）：

```json
{
  "adaptiveScoring": {
    "expectedCharacterCount": 7,
    "minimumCorrect": 4
  },
  "snrNoise": {
    "ssn": "SSN-MSP.wav",
    "babble": "Babble-MSP.wav"
  }
}
```

文件为 UTF-8，可带 BOM，文件名及字段名区分大小写。`expectedCharacterCount`、`minimumCorrect` 均为正整数，后者不超过前者；每库固定字数。内置 MSP 为 7／4，MHINT、MHINT-P 为 10／8。评分按 Unicode 文本元素，排除空白和标点、保留数字。

噪声值仅允许 `SpeechNoises` 内大小写准确的 `.wav` 文件名，不允许路径或文件链接。MHINT-P 的映射复用 MHINT 文件。校准参考为 `SSN-MSP.wav`；两种 SNR 和固定 RIR 均需要它，RIR 关闭加噪也需要。

| 模式 | 额外资源要求 |
| --- | --- |
| 固定语速 | 有效语音，不要求评分规则或噪声映射 |
| 自适应语速 | 有效评分规则，所选句表每句字数匹配 |
| 固定 SNR | 所选噪声映射、噪声和校准参考，不要求自适应评分规则 |
| 自适应 SNR | 自适应评分要求，以及所选噪声和校准参考 |
| 固定 RIR | 有效房间设置及校准参考；启用加噪时还需要所选噪声 |

缺失或非法评分配置只影响相应自适应能力，不阻止其他有效语料加载；噪声映射独立解析。缺失或损坏整个 JSON 会使需要噪声映射的模式不可用。使用会话的可用性属性获取具体原因，避免自行按语料名称推断能力。

## 最小完整会话示例

### 配置来源与独立宿主边界

控制台不必传入或复制桌面应用的配置文件。训练核心不读取桌面的 appsettings 或环境变量；宿主可从代码、命令行或自己的 JSON 读取值，再构造设置对象。引用类库不会自动继承桌面当前配置。

| 配置 | 独立宿主提供方式 |
| --- | --- |
| 训练模式、语速、SNR、声码器、包络提取、房间 | `TrainingAudioSettings`、`ConfigureAudio` 及会话设置方法，在开始前配置 |
| 包络最大电流、延时、调试频率、通道掩码 | `EnvelopePlaybackSettings`，通过 `AttachStimulation`／`ConfigureStimulationAsync` 传入 |
| 网络、真实/模拟能力、心跳 | `DeviceRuntimeOptions`、`DeviceBackendProfile`，见[通信复用说明书](通信库跨项目复用说明书.md) |
| 协议修订、校验、请求超时 | `EggtCsModuleOptions`、`EggtCsProtocolOptions` |
| 设备输出的停止超时、电流限制与步进 | 由输出适配器的宿主显式配置，不自动继承桌面策略 |

资源提供器仍会读取 `SpeechCorpora`、`SpeechNoises` 及语料的 `corpus.json`；这是资源和元数据，不是桌面应用配置。默认根目录为输出目录，也可用提供器构造参数指定目录，或实现自定义资源接口。各模式需要哪些资源见前表。内置 MSP、MHINT、MHINT-P 的会话评分规则在代码中固定；自定义语料使用 `SetScoringRule` 覆盖值或 `Corpus.AdaptiveScoring`，不要假定修改内置语料 JSON 就会改变会话评分阈值。

### 纯音频控制台程序

将前述项目的 `Program.cs` 替换为以下代码。它使用内置练习语料，创建仅含一句的句表，实际播放、收集逐字评分并输出结果；每个评分应由真实回答判定。

<!-- speech-session:program -->
```csharp
using EGGtCSPlatform.Audio.Sdl;
using EGGtCSPlatform.SpeechTraining;

var corpora = new FileSpeechCorpusProvider();
using var session = new SpeechTrainingSession(corpora, new SdlAudioPlayer(), listSize: 1);
session.SelectCorpus("MHINT-P");
session.SelectSentenceList("01");
session.SelectMode(SpeechTrainingMode.FixedRate);
session.SetSpeechRate(0);
session.Volume = 0.5;

var completed = new TaskCompletionSource(TaskCreationOptions.RunContinuationsAsynchronously);
session.Changed += (_, _) =>
{
    if (session.Error is { } error)
        completed.TrySetException(new IOException(error));
    else if (session.CanScore && !session.IsPlaying)
        completed.TrySetResult();
};

if (!session.CanStart)
    throw new InvalidOperationException("当前设置无法开始训练。");
Console.WriteLine(session.CurrentSentence.Text);
await session.StartAsync(); // 返回表示本次启动处理完成，不表示已经播完
await completed.Task.WaitAsync(TimeSpan.FromSeconds(60));
for (int i = 0; i < session.CurrentSentence.ScoringCharacters.Count; i++)
{
    Console.Write($"{session.CurrentSentence.ScoringCharacters[i]} 正确吗？y/n：");
    string answer;
    do
    {
        answer = (Console.ReadLine() ?? throw new EndOfStreamException("评分输入已结束。"))
            .Trim().ToLowerInvariant();
    } while (answer is not ("y" or "n"));
    session.Rate(i, answer == "y");
}
if (!session.CanSaveNext)
    throw new InvalidOperationException(session.Error ?? "本句尚不能保存。");
await session.SaveNextAsync(); // 当前只有一句，保存后自动结束
var result = session.Result ?? throw new InvalidOperationException("未生成结果。");
Console.WriteLine($"已保存 {result.Sentences.Count}/{result.SentenceCount} 句");
Console.WriteLine($"正确 {result.CorrectCount}/{result.RatedCount}，正确率 {result.Accuracy:P1}");
```

```powershell
dotnet run --project artifacts/SpeechTrainingGuide
```

SDL 播放器必须在应用主线程创建。会话拥有播放器，`Dispose` 会停止并释放它。若换成多句句表，`SaveNextAsync` 会自动启动下一句，需要为下一次播放重新建立等待条件；不要复用已完成的 `TaskCompletionSource`。

## 常用 API

### 会话构造与替换点

构造参数为 `SpeechTrainingSession(provider, player, listSize = 20, preparation = null, noiseProvider = null, rirGenerator = null)`。

| 接口 | 调用方职责 |
| --- | --- |
| `ISpeechCorpusProvider` | 提供 `Corpora`、`ReadAudio`；可重写 `ReadAudioResource` 携带文件哈希，默认文件哈希为 null |
| `IAudioPlayer` | 实现启动、停止、音量、进度、事件和释放；详见[音频指南](音频处理模块复用指南.md#播放接入) |
| `ISpeechNoiseProvider` | 提供 `Read(fileName)`、`CalibrationRms`；可提供 `CalibrationResource` |
| `IRirGenerator` | 提供匹配房间条件的 `RirResponse` |
| `ITrainingAudioPreparationService` | 实现 `CreateRequest`、`Prepare`，返回符合当前内置预设的准备结果 |

准备结果仍会被会话验证，不能通过注入准备服务接入任意自定义图。自由组合处理器使用[音频复用指南的完整 DAG 示例](音频处理模块复用指南.md#完整-dag-示例)，自行管理训练业务。

### 配置、操作和状态

| API | 用途及可用时机 |
| --- | --- |
| `SelectCorpus`／`SelectListSize`／`SelectSentenceList` | 开始前选择资源；切库和改大小重置到第一表，切库保留大小 |
| `SelectMode`／`ConfigureAudio` | 开始前设置模式或完整 `TrainingAudioSettings` |
| `SetSpeechRate` | 仅固定语速模式，0 原速或 1～5 整数字/秒；检查 `CanAdjustSpeechRate` |
| `SetVocoder` | 启用或更新载体，传 null 关闭；检查 `CanAdjustCarrier` |
| `SetInitialSnr`／`SetFixedSnr`／`SelectNoise`／`SetRir` | 设置对应模式条件，开始后锁定 |
| `StartAsync`／`ReplayAsync` | 开始或重播，分别检查 `CanStart`、`CanReplay` |
| `Rate(index, bool?)`／`RateAll(bool?)` | 逐字或全部评分，null 清除判定；检查 `CanScore` |
| `SaveNextAsync` | 保存当前完整评分并播放下一句，末句自动结束；检查 `CanSaveNext` |
| `StopAsync` | 取消本地播放，等待活动任务清理及输出适配器停止；中断句须重播 |
| `EndAsync` | 等待停止、通过持久化边界保存结束快照并结束；不保存未提交评分 |
| `Stop`／`End` | 同步取消／结束入口，不等待设备停止确认，也不代替异步持久化收尾 |
| `Dispose` | 释放会话与播放器；绑定设备输出时先等待 StopAsync／EndAsync 完成 |
| `AttachStimulation`／`ConfigureStimulationAsync` | 开始前绑定一次输出／在 CanAdjustStimulation 为真时更新设置 |
| `Changed` | 状态变化通知；可能来自后台线程，UI 应异步调度 |
| `Volume`／`VolumeError` | 音量 0～1；设置失败保留原值并报告，不终止评分 |

多数操作在不可用时直接返回，调用方应根据 `Can…` 属性控制操作，而不是等待必然抛异常。`StartAsync` 的准备失败也可能写入 `Error` 而不抛出给调用方，必须订阅通知或检查状态。

| 状态／数据 | 用途 |
| --- | --- |
| `CanConfigure`、`Started`、`Ended`、`IsLoading`、`IsPlaying` | 界面或宿主的操作可用性 |
| `CanAdjustStimulation`、`IsPreparingStimulus`、`IsOutputBusy`、`OutputStatus` | 刺激配置可用性、计划准备和输出状态；音频结束不等于输出已完成 |
| `Corpora`、`Corpus`、`Lists`、`SentenceList`、`CurrentSentence`、`SentenceIndex` | 当前选择与句子；索引从零开始 |
| `Answers`、`CanScore`、`CanSaveNext` | 已判定答案与提交条件 |
| `AudioSettings`／`CurrentAudioSettings` | 下次播放设置／当前实际使用设置 |
| `Audio`、`Waveform`、`Position`、`Duration` | 实际播放数据、显示数据和进度 |
| `CurrentTiming`、`CurrentSnrDb`、`AdaptiveR` | 自适应模式的当前信息 |
| `AdaptiveReversals`／`AdaptiveSubmissions`、`SnrReversals`／`SnrSubmissions` | 自适应语速／SNR 的反转数和已提交记录 |
| `Error`、各模式的 `…UnavailableReason` | 准备／播放错误及开始前不可用原因 |
| `Result` | 结束后读取的内存结果 |

## 控制台接入语音包络刺激

训练核心可独立引用，但仓库当前的 `DeviceEnvelopeOutput` 位于桌面主项目，依赖该项目的心跳接口、电流策略和路由模型；引用 SpeechTraining 与设备类库不会自动获得它。完整真机接入需抽取该适配器及必要策略，或由宿主实现 [ISpeechStimulationOutput](../EGGtCSPlatform.SpeechTraining/Sessions/ISpeechStimulationOutput.cs)。不要为了复用而把整个桌面项目作为控制台依赖。

1. 按通信复用说明书建立 Runtime，发现并连接目标设备，明确 Stimulation 能力来源和协议修订。
2. 创建资源提供器、播放器及 SpeechTrainingSession，在开始前设置训练条件。
3. 创建面向目标设备的输出适配器，构造 EnvelopePlaybackSettings，调用 AttachStimulation。
4. 订阅 Changed，结合 Error、OutputStatus 和 Can… 属性操作；开始、重播和保存下一句均使用异步方法。
5. 退出前等待 EndAsync（或仅停止时 StopAsync），确认输出收尾，再释放会话及 Runtime。会话拥有播放器；输出适配器自身的资源由宿主管理。

输出接口职责如下；仅转发配置和启动两个命令不足以保留桌面行为：

| 成员 | 适配器职责 |
| --- | --- |
| `PrepareAsync(plan, token)` | 检查设备/协议/参数与运行状态，必要时先确认停止，再配置计划字节 |
| `StartAsync(token)` | 检查已配置且可启动，处理启动响应；成功后会话才开始音频播放 |
| `WaitForCompletionAsync(token)` | 等待本次输出完成条件；桌面实现按启动响应后的延时＋样本时长等待并监测故障，不等同于硬件完成测量 |
| `StopAsync()` | 用独立的清理超时确认停止，不复用已取消的播放令牌；不确定状态不得当作成功 |
| `Status`、`Changed`、`Faulted` | 向会话传播输出状态与故障 |

EnvelopePlaybackSettings 含 MaximumCurrent（mA）、DelayMilliseconds、DebugFrequencyHz、ChannelMask。模型校验电流为 `(0, 255×0.033]`、延时 0～300 ms、频率 200～1000 Hz、掩码非零；这只是模型范围，不替代宿主电流策略和实际设备限制。桌面适配器另做电极角色校验，仅将自选通道写入掩码。当前桌面训练固定 500 Hz，不意味着独立模型只接受 500 Hz。

参数防御属于不同层：SpeechTrainingSession 在方法内部检查并锁定训练参数，`CanConfigure = !Started && !_disposed && !IsCommitting`，不是只靠 UI。播放完成、Stop、失败和正常结束均不会把已开始会话恢复为可配置状态；下一轮创建新会话。音量是例外，可在训练中调整。多数不允许的调用直接返回，Task 正常完成不保证修改成功。

设备就绪、停止确认和故障后锁定由 DeviceEnvelopeOutput 实现，不能假定自定义输出自动具有相同行为。直接调用 SDK 的 `device.EnvelopeStimulation.ConfigureAsync` 会绕过训练状态限制；SDK 并未提供全局的“训练期间禁止配置”互斥。宿主应统一设备操作入口。

Changed 可能来自后台线程，会话也转发适配器 Changed/Faulted。`IsPlaying=false` 不代表可以切句；使用 CanReplay、CanSaveNext、IsOutputBusy。这些状态基于本地流程和收到的设备反馈，不是物理输出的实时测量。异步输出任务返回后仍需检查 Error；停止失败时不要继续启动新操作。

## 五种训练模式示例

以下片段彼此独立，放在完整示例中创建、选好语料后的 `StartAsync` 之前，替换原模式配置。上下文为尚未开始的 `session`；使用同一命名空间。配置后统一通过 `CanStart`、`StartAsync` 和错误通知开始。

### 固定语速

<!-- speech-mode:fixed-rate -->
```csharp
session.SelectMode(SpeechTrainingMode.FixedRate);
session.SetSpeechRate(2); // 2 字/秒；0 表示原速
```

默认固定语速、0 原速。语速只允许 0～5 整数；仅开始前可调速，开始后整轮锁定。

### 自适应语速

<!-- speech-mode:adaptive-rate -->
```csharp
session.SelectMode(SpeechTrainingMode.AdaptiveRate);
if (!session.CanUseAdaptiveMode)
    throw new InvalidOperationException(session.AdaptiveUnavailableReason);
```

需要有效评分配置和当前句表字数匹配。不调用手动调速；按 `CurrentTiming` 读取实际语速信息，未准备时可为空。只有保存完整评分才会推进，重播不推进。规则计算见原理文档。

### 固定 SNR

<!-- speech-mode:fixed-snr -->
```csharp
session.SelectMode(SpeechTrainingMode.FixedSnr);
session.SetFixedSnr(-7.25);
session.SelectNoise(SpeechNoiseKind.Babble);
if (!session.CanUseFixedSnr)
    throw new InvalidOperationException(session.FixedSnrUnavailableReason);
```

默认 10 dB；允许负值和超过 20 dB，必须有限。极端值若无法有效处理，会在准备时明确失败。固定值与自适应初始值独立保存；全表使用固定条件，不生成自适应阈值。

### 自适应 SNR

<!-- speech-mode:adaptive-snr -->
```csharp
session.SelectMode(SpeechTrainingMode.AdaptiveSnr);
session.SetInitialSnr(10);
session.SelectNoise(SpeechNoiseKind.Ssn);
if (!session.CanUseAdaptiveSnr)
    throw new InvalidOperationException(session.SnrUnavailableReason);
```

初始值默认 10 dB，允许 0～20。开始后模式、初始值和噪声锁定。可用 `GetNoiseUnavailableReason(kind)` 检查资源，`GetSnrUnavailableReason(kind)` 同时检查自适应条件。实际后续值可能为负。

### 固定 RIR

<!-- speech-mode:fixed-rir -->
```csharp
session.SelectMode(SpeechTrainingMode.FixedRir);
session.SetRir(TrainingRoomSettings.Default with
{
    AddNoise = true,
    NoiseKind = SpeechNoiseKind.Babble,
    SnrDb = -10
});
if (session.RirUnavailableReason is { } reason)
    throw new InvalidOperationException(reason);
await session.GenerateRirAsync(); // 可选；StartAsync 也会自动准备
if (session.Error is { } error)
    throw new InvalidOperationException(error);
```

`TrainingRoomSettings` 的 `Acoustics` 使用通用 `RirSettings`；`AddNoise=false`、`NoiseKind=Ssn`、`SnrDb=10` 为默认业务值。房间参数用法见[音频指南的处理器手册](音频处理模块复用指南.md#内置处理器使用手册)。`RirPreview` 提供响应数据，`IsGeneratingRir`、`CanCancelRir` 和 `CancelRir()` 用于取消生成／首次准备。关闭噪声仍需校准参考，不需要自适应评分规则。

### 载体和包络选项

下列片段只能放在开始前。`CanAdjustCarrier` 包含 `CanConfigure` 条件，因此训练开始后 `SetVocoder` 也不能更新；音频包络只能开始前通过 `ConfigureAudio` 设置。

<!-- speech-options:carrier-envelope -->
```csharp
using EGGtCSPlatform.Audio.Dsp.Conversion;
using EGGtCSPlatform.Audio.Dsp.Envelope;
using EGGtCSPlatform.Audio.Dsp.Vocoder;

session.SetVocoder(new VocoderOptions(
    Algorithm: VocoderAlgorithm.ClassicalCis,
    Bands: 8, Carrier: VocoderCarrier.Noise, Maxima: 8, Seed: 1729));
session.ConfigureAudio(session.AudioSettings with
{
    Envelope = new EnvelopeOptions(
        CutoffHz: 200, FilterOrder: 4, ChannelMode: ChannelMixMode.Average)
});
```

片段中的 using 放在 Program.cs 顶部。`SetVocoder(null)` 关闭声码器。默认包络选项为 `EnableFilter=false`（低通关闭）、声道平均；低通参数保留 150 Hz、五阶，仅显式设置 `EnableFilter=true` 时生效，参数范围见音频指南。待生效配置变更不清除当前波形或评分；直接保存仍记录实际播放过的配置。

## 独立音频准备

仅需要某句训练音频和显示数据时，不必创建会话或播放器。下面是独立的完整 `Program.cs`，只需引用 SpeechTraining；使用输出目录的内置资源，准备固定 SNR 音频，不发声、不评分。

<!-- speech-preparation:program -->
```csharp
using EGGtCSPlatform.SpeechTraining;

var corpora = new FileSpeechCorpusProvider();
var corpus = corpora.Corpora.Single(c => c.Id == "MHINT-P");
var sentence = new SpeechSentenceListService().GetSentence(
    corpus, size: 20, listNumber: 1, sentenceNumber: 1);
var service = new TrainingAudioPreparationService(corpora, new FileSpeechNoiseProvider());
var settings = new TrainingAudioSettings(
    Mode: SpeechTrainingMode.FixedSnr,
    NoiseKind: SpeechNoiseKind.Babble,
    SnrDb: 5);
using var cancellation = new CancellationTokenSource();
var token = cancellation.Token;
var prepared = await Task.Run(() =>
{
    var request = service.CreateRequest(
        sentence, settings, speedMultiplier: 1, seed: 1729,
        noiseMapping: corpus.SnrNoise, token: token);
    return service.Prepare(request, token: token);
}, token);
prepared.ValidateRequest();
var display = SpeechWaveformData.Prepare(prepared, token);
Console.WriteLine($"播放：{prepared.Playback.Frames} 帧");
Console.WriteLine($"包络：{prepared.Envelope.Frames} 帧");
Console.WriteLine($"参考起点：{prepared.EnvelopeSource.Timeline.StartSeconds} 秒");
Console.WriteLine($"显示：{display.Voice.Count} 个波形桶");
Console.WriteLine($"资源：{prepared.Snapshot.Resources.Length}，节点：{prepared.Snapshot.Nodes.Length}");
```

`CreateRequest`、`Prepare` 和显示准备均为同步 API；UI 调用方应把包括 `SpeechWaveformData.Prepare` 在内的耗时工作放到后台。自适应语速的 `speedMultiplier` 必须提供实际正有限倍率；其他模式通常传 1。`seed` 由调用方确定并保存。

| 准备结果成员 | 使用方式 |
| --- | --- |
| `Pipeline` | 本次图定义，供检查连接 |
| `Graph` | 通用执行结果与记录 |
| `Playback` | PCM16 播放缓冲区 |
| `EnvelopeSource` | 干净参考及时间信息 |
| `Envelope` | 完整单声道浮点包络 |
| `Snapshot` | 实际设置、资源身份、图与执行摘要 |
| `TimeStretch`／`Noise`／`Rir` | 按模式可为空的元数据 |
| `RirResponse` | RIR 模式的响应，可供预览 |

需要尝试复用已有准备结果时，在同一服务中重新创建当前请求，并调用 `Prepare(request, cached: previous, token: token)`。不要只比较界面显示文字或手工构造一个结果冒充当前请求。准备结果提供 `playback`、`envelopeSource`、`envelope` 三个固定出口；任意 DAG 使用通用执行器。

## 评分与结果读取

播放中可在 `CanScore` 为真时评分；`Rate` 索引对应 `CurrentSentence.ScoringCharacters`，不是原字符串的字符下标。完整评分只是提交条件之一，绑定刺激时还要等待输出完成，最终以 `CanSaveNext` 为准；持久化失败后的待提交快照有独立重试分支。重播保留答案，下一句重置；末句只结算一次。使用 `await EndAsync()` 提前结束，结果不包含未提交评分。

以下片段用于已结束、具有 `Result` 的 `session`；完整示例末尾可以直接追加：

<!-- speech-result:snippet -->
```csharp
var trainingResult = session.Result
    ?? throw new InvalidOperationException("请先完成训练或调用 End。");
Console.WriteLine($"模式：{trainingResult.Settings.TrainingMode}");
Console.WriteLine($"已提交：{trainingResult.Sentences.Count}/{trainingResult.SentenceCount}");
foreach (var item in trainingResult.Sentences)
{
    Console.WriteLine($"{item.SentenceId}: {item.Correct}/{item.Total}, " +
        $"已播完={item.PlaybackCompleted?.ToString() ?? "未记录"}");
    if (item.AudioSnapshot is { } snapshot)
        Console.WriteLine($"载体：{snapshot.Settings.CarrierSummary}，种子：{snapshot.Seed}");
}
if (trainingResult.AdaptiveSummary is { } rateSummary)
    Console.WriteLine(rateSummary);
if (trainingResult.SnrSummary is { } snrSummary)
    Console.WriteLine(snrSummary);
Console.WriteLine($"实际播放次数：{trainingResult.Playbacks.Length}");
```

| 结果成员 | 含义及注意事项 |
| --- | --- |
| `Settings` | 开始训练时的设置，不是最后一次待生效值 |
| `SentenceCount`／`Sentences.Count` | 计划句数／实际提交句数 |
| `CorrectCount`／`RatedCount`／`Accuracy` | 已提交正确字数／已评分字数／正确率；零提交时正确率为 null |
| `SpeechSentenceResult.AudioSnapshot` | 该句实际播放条件，不从当前设置推断 |
| `Adaptive`／`AdaptiveSnr`／`Noise`／`Rir` | 模式相关记录，使用前判空 |
| `Playbacks` | 确认启动的播放，包括重播和未提交句；不是得分列表 |
| `AdaptiveSummary`／`SnrSummary` | 自适应结果，完整提交且足够样本才有阈值；混合载体须按其标签解释 |

固定语速、固定 SNR、固定 RIR 不生成自适应阈值。两种自适应摘要要求完整完成且至少 8 句；不足时读取状态，不把缺失值当作 0。历史记录缺字段应显示“未记录”，不要用当前资源补填。

核心提供内存结果和可选的异步持久化提交边界；版本迁移、导出及恢复由宿主实现，桌面应用已实现言语实验持久化。当前 API 不提供从快照恢复并执行训练的入口。核心通过可选的 ISpeechStimulationOutput 协调设备输出，自身不实现设备通信。

## 复用注意事项

- 模式、语料、句表、评分规则、语速、载体及 SNR／房间条件开始后整轮锁定；开始前检查 `CanConfigure`／`CanAdjustSpeechRate`／`CanAdjustCarrier`。不要绕过能力属性。
- 重播读取当前请求条件；语料 WAV 会重新读取，语料配置在提供器创建时冻结。噪声和读取失败在提供器内缓存，修改资源后新建提供器／会话。
- 缓存是否可复用由服务决定，资源身份、内容、参数、种子或出口改变会使其失效。音量只是播放器输出增益，不触发音频准备，也不写入结果。
- `Changed` 与播放器事件可能来自后台线程。UI 用异步投递，不在回调中同步等待 UI 或其他线程。
- 会话负责播放器生命周期，一个会话使用独立播放器。替代播放器应正确报告 PlaybackId、Playing／Completed／Failed，停止后不要把旧事件当新播放。
- 出错时检查 `Error`；评分保存受状态限制。失败后用可用的重播操作重试，不自动跳句。取消／停止中断的句子须重播后继续评分；下一句失败不撤销上一句已经提交的分数。
- `Waveform` 可能为空，准备期间显示等待或空网格。显示桶不能直接当作设备命令；包络输出使用 `EnvelopePlaybackPlan`，设备通信由宿主适配器负责，数据库由持久化回调负责。
- UI 或独立宿主需自行提供训练结束后的存储；在 Dispose 前取得需要保留的 Result。

### 多轮与持久化接入

每一轮创建新的 `SpeechTrainingSession`，不要复用已结束实例。继承配置时使用上一轮 `Snapshot().Settings` 中的初始值：恢复语料、句表与句数后调用 `ConfigureAudio`，并用 `SetScoringRule(settings.AdaptiveScoring)` 恢复评分规则。不要使用自适应算法结束时的当前值代替初始值。

可设置 `session.PersistAsync = async (result, ended) => ...`：宿主保存完整结果快照后返回。回调失败会保留原句提交内容，重试 `SaveNextAsync` 不会重复推进句次或算法；回调不依赖数据库、页面或设备类型。已提交记录应按宿主分配的训练 ID 与句次幂等保存。退出使用 `EndAsync` 等待输出停止并持久化，未提交评分不会进入结果。音量不属于锁定的实验条件，可随时调整。
