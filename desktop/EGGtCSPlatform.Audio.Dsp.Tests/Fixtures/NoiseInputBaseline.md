# 双输入加噪迁移基线

`NoiseInputBaseline.json` 在修改普通加噪、RIR 和噪声匹配实现之前捕获。
原始 DSP 程序集 SHA256：
`DCE544EFA1339DF19EDB7C581B93BF83E8A2BFE1DA14DEC67BB894B52FD10B16`。

64 个组合包含普通加噪／RIR、11025／16000 Hz 噪声、单／双声道语音和噪声、
8／4096 帧噪声、偏移 0／目标帧数减一。语音为 16000 Hz、137 帧，
SNR 为 -3 dB，校准 RMS 为 0.05；RIR 使用默认几何、T60 和响应长度均为 0.15 秒。

输入 PCM 原样保存在夹具中。匹配后的声道数组按声道顺序连接，以原始 double 字节
计算 SHA256；播放结果比较 PCM SHA256；归一化、峰值增益、RMS 与 RIR 标量逐值比较。
测试只生成实际值，不更新期望值。不要用迁移后的实现重建此夹具。
