# 电极位置配置与 3D 构建

两种视图共用 `ElectrodePositions.Positions`。每条记录的 `Id` 是稳定业务标识（大小写不敏感），`Position` 是显示名称。不要通过改名或调换 ID 来调整方向；物理通道映射引用的是 ID。

```json
{
  "Id": "F3",
  "Position": "F3",
  "ReferenceX": 204,
  "ReferenceY": 183,
  "DefaultRole": "None",
  "Position3D": { "X": -44.101533, "Y": 42.386528, "Z": 45.222849 },
  "Normal3D": { "X": -0.6251879930496216, "Y": 0.28757762908935547, "Z": 0.725561261177063 }
}
```

示例来自默认 F3 配置，其余默认点位见 `appsettings.default.json`。用户配置位于 `%LOCALAPPDATA%/EGGtCSPlatform/appsettings.json`；修改后重启生效。现有二维坐标按 572×574 参考画布解释，其绘制缩放不变。

## 三维坐标

### 电极配置坐标系

`Position3D` 和 `Normal3D` 使用相同的坐标轴方向，左右始终以人物（佩戴者）自身为准：

| 配置轴 | 正方向 | 负方向 |
| --- | --- | --- |
| X | 人物右侧，右耳方向 | 人物左侧，左耳方向 |
| Y | 人物前方，鼻子朝向 | 人物后方，后脑方向 |
| Z | 上方，头顶方向 | 下方，颈部方向 |

F3 的 X 为负，F4 为正。面对人物时，人物右侧对应观察者左侧；旋转观察视角不会改变坐标轴相对于人物的方向。

`Position3D` 的原点是程序选定的固定参考点，对应 GLB 模型坐标 `(0, 0.25594061613082886, 0)`（米）。即从模型原点沿模型 Y 轴向上约 255.94 mm。代码将其命名为 `MODEL_CENTER`，但它不是动态计算的包围盒中心，也不是经过解剖标定的中心、鼻尖或 Cz。增删电极不会改变此参考点。

### Position3D：电极放在哪里

`Position3D` 表示电极面的中心相对于上述配置原点的位置，单位为毫米。例如 `(-40, 30, 50)` 表示左侧 40 mm、前方 30 mm、上方 50 mm。它控制位置，不控制电极面的倾斜方向。

### Normal3D：电极面朝向哪里

`Normal3D` 是电极平面的法向量，即垂直于电极平面、指向头部外侧的方向。它使用配置坐标轴，但作为方向向量没有固定的位置原点，也不表示另一个电极位置。

可以把 `(nx, ny, nz)` 想象成从坐标原点指向该三元组的箭头，然后把箭头平移到电极中心：只取箭头的方向，不取其终点位置和长度。程序会将它归一化，因此 `(-1, 0, 1)` 与 `(-2, 0, 2)` 都表示向左上方。`(0, 0, 1)` 表示电极面朝上，电极平面平行于配置 XY 平面。

```json
{
  "Position3D": { "X": -40, "Y": 30, "Z": 50 },
  "Normal3D": { "X": -1, "Y": 0, "Z": 1 }
}
```

此例表示电极位于配置原点左 40 mm、前 30 mm、上 50 mm，电极面朝左上方。修改 `Position3D` 会移动电极；保持位置不变、只修改 `Normal3D`，会在原位置调整电极朝向。

`Normal3D` 可省略，此时程序使用“配置原点 → 电极位置”的方向，即归一化后的 `Position3D`，作为朝外法向量。真实帽体不是球面，此方向不一定垂直于局部表面，可单独配置法向量来调整朝向。零向量、非有限数值等无效法向量会禁用 3D 并提示问题点位；若电极位于配置原点，必须显式提供有效的法向量。

配置位置按原样放置，不自动吸附到头帽表面。修改法向量不会移动电极，也不会自动修正电极嵌入头模的深度。

### GLB 模型坐标系

GLB 模型自带的原点 `(0, 0, 0)` 由建模、导出时的坐标设置决定。对当前 `eeg-head.glb`，原点位于头颈模型最下方、颈部底面附近的中央位置，不在脑袋中心。实际 `HEAD` 几何范围中，最低处模型 Y 约为 0，头顶最高处约为 0.320 m，左右模型 X 范围约为 −0.076～+0.076 m；这些是当前资源的几何测量值，不代表所有 GLB 模型的约定。

当前模型坐标以米为单位，轴方向如下：

| 模型轴 | 正方向 | 负方向 |
| --- | --- | --- |
| X | 人物左侧，左耳方向 | 人物右侧，右耳方向 |
| Y | 上方，头顶方向 | 下方，颈部方向 |
| Z | 人物前方，鼻子朝向 | 人物后方，后脑方向 |

因此，GLB 原点与电极配置原点不同，两套坐标轴也不能直接混用。更换模型资源时，需要重新核对原点、轴方向、尺度及配置参考点。

### 配置坐标与模型坐标的转换

唯一的模型转换在 `electrode-layout.js`：

```text
model.x = -X / 1000
model.y = 0.25594061613082886 + Z / 1000
model.z = Y / 1000
```

法向量只转换方向，不添加原点偏移，也不需要毫米到米的单位换算：

```text
model.normal = normalize(-Normal3D.X, Normal3D.Z, Normal3D.Y)
```

省略 `Normal3D` 时，上式使用 `Position3D` 的 XYZ 分量代替。`normalize` 表示将向量长度调整为 1，方向保持不变。

二维 `ReferenceX/Y` 使用独立的 572×574 参考画布，原点在画布左上角，X 向右、Y 向下。二维和三维共享电极身份及数量，但位置分别配置；修改三维位置不会移动二维位置，反之亦然。

## 点位数量与通道配置

新增点位只需在共享列表增加记录，不需要 GLB 中存在对应名字；删除记录会同时删除两种视图的逻辑点位。三维缺少位置或存在非法坐标/朝向时，整幅 3D 禁用并列出问题 ID，二维有效时仍能使用。二维 ID 重复等原有配置错误仍按原有校验处理。

显示点位数量不代表设备通道数量。新增刺激点位还需配置 `StimulationChannels.AllowedElectrodeSiteIds`；采集使用 `EegAcquisitionChannels.ElectrodeMappings`。删除点位时应同步清理这些引用。程序不自动分配或重排物理通道。

## 兼容与资源

配置 schemaVersion 为 2。旧配置启动迁移先备份，再按 ID 为默认已知点位补齐几何；不恢复已删除点位，不改变二维坐标、显示名、顺序或通道映射。自定义点位需手动补充三维位置。版本 2 的缺失/非法几何不会被静默替换成其他点位。

模型保留头、帽和电极造型。加载时把原 `E_Cz` 电极提取为局部模板，去除固定电极和固定布局的线缆、线夹，再按配置克隆定位。点位列表及坐标统一来自 `ElectrodePositions.Positions`，不再保留独立的固定点位 JSON 资源。`eeg-head.glb` 仍用于加载头模、帽体和电极造型模板，配置点位数量不受模型中原有电极数量限制。标准头模位置仅用于展示，不代表个人实测电极定位。

## 可复现构建与验收

### 加载反馈

进入 3D 时，全程由 Avalonia 显示同一套点状加载动画和“正在加载 3D 头模…”文字。WebView、网页和交互遮罩背景透明，不重复绘制动画或文字；加载期间模型区域保持布局与渲染，但透明度为零，避免露出未完成的模型和标签。`ready` 仅表示模型已加载、网页可以接收配置；首次应用点位配置并渲染电极首帧后，网页发送 `scenePresented`，移除加载层并启用交互。加载成功前不显示百分比，启动超过 30 秒仍未完成首帧时显示失败提示，可切回 2D。

弹窗期间继续隐藏原生 WebView，关闭后恢复当前加载或显示状态。切回 2D 或离开页面时取消加载并释放动画；下次进入重新加载。测试宿主 `head3d-dialog` 覆盖延迟模型响应、透明背景与单一动画、首帧通知、超时、错误和加载期间离开；`head3d-dialog-loading-preview` 会停在加载画面供原生窗口检查，点击“继续加载验收”后完成其余自动回归。测试延迟和短超时仅由测试宿主设置，正式使用保持默认值。

### 构建命令

导航离开电极页面时，在 `CurrentPage` / `CurrentView` 属性变更前同步隐藏并退出 3D，不等待滑动转场结束。返回被阻止或导航目标仍是当前页时保留模型；弹窗关闭继续恢复原实例。视觉树分离仍执行兜底清理。`head3d-dialog-navigation-preview` 使用正式导航宿主，在 3D 就绪后等待实际点击返回，并验证返回上级、首页、前进、加载途中返回及关闭导航动画时的同步退出。

在本目录执行（Node.js 22 或更新版本）：

```powershell
npm ci
npm test
npm run build
```

依赖版本及完整性锁定在 `package-lock.json`。将生成的 `scene.js` 与源码一起交付；应用运行时完全使用嵌入资源，无需联网。修改网页源码后必须重新打包，再构建 .NET 项目。

`npm test` 覆盖解剖方向、实际 GLB 模板提取及 2/34/40 点布局；.NET 测试覆盖迁移、缺失与非法配置以及稳定 ID。原生视觉回归使用 `head3d-dialog`、`head3d-dialog-interactive` 和 `electrode-configuration-3d`，需要 Windows WebView2 运行环境及本机回环 HTTP。交互场景中视角保留检查实际相机、目标及标签 transform，不能用离屏截图替代原生窗口验收。

## 刺激和采集共用点位

`appsettings` 的 `ElectrodeSelection.AllowSharedStimulationAcquisitionSite` 默认 `true`，允许刺激与采集、REF 或 GND 共用点位；设为 `false` 恢复互斥，重启应用生效。刺激白名单、物理通道约束和采集侧角色唯一性仍然有效。

共用点位上半为刺激，下半为“采”/REF/GND，中间虚线分隔。两侧检测颜色和阻抗分别保存，清除仅作用于当前模式。REF/GND 和固定刺激通道保持无需检测，其头模区域在对应模式收到阻抗检测结果后显示最低阻值档绿色和白色文字，配置时保持未检测样式，不生成阻抗读数；列表和提示仍显示“无需检测”。刺激模式中的不可选样式优先。关闭共用时，包含共用点位的模板不能应用。
