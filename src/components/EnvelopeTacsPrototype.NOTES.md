# 包络-tACS 页面流程原型

- 原型问题：从新建单刺激实验到逐句回答判分，页面内容、按钮门禁和状态切换是否完整、顺畅。
- 入口：`/?screen=envelope-tacs-prototype`
- 范围：纯前端内存状态，不连接真实设备，不采集 EEG，不录音，不自动判分。
- 刺激方案字段来源：MATLAB 代码明确提供波形类型与刺激模块初始化；旧界面截图及包络算法图提供刺激模式类型、最大电流、包络低通截止频率、相对延迟、限制电流比例、载波频率和占空比。
- 已删除无旧代码／截图依据的调制深度、缓升缓降、相位和时序选择字段。音频与刺激仍按当前原型流程联合启动，但不再把该行为包装成旧界面配置字段。
- 实验页用同一时间轴展示原始语音及上下包络、包络调制载波电流，并提供 50 ms 载波放大窗；全句总览中的高频载波为压缩示意，不冒充逐采样设备反馈。
- 截图分辨率较低，频率、延迟和比例标签采用可辨认语义；接入真实设备前仍需用完整 `.fig`／设备协议核对准确命名、单位、范围与下发顺序。
- 使用完成后：把确认后的状态机和字段吸收到正式页面，再删除此原型组件。
