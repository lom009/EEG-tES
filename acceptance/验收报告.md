## 命令

在 `/Users/fengyinan/Documents/EEG-tES` 执行。辅助脚本 `acceptance/dotnet-local` 使用本机外置盘已有的 .NET SDK 和 NuGet 缓存。B 是功能开发前执行的命令，复现相同基线需使用上述源码加旧包络补丁。

```sh
# U

SDL_AUDIODRIVER=dummy acceptance/dotnet-local run --no-build --project desktop/EGGtCSPlatform.VisualTests -- --scenario=picture-naming --output-directory=/Users/fengyinan/Documents/EEG-tES/acceptance/verified --timeout-seconds=45

codesign --verify --deep --strict --verbose=1 output/EGGtCSPlatform-tDCS.app
```

## 首次失败与修复

- 首轮基线因沙箱限制本机测试进程创建套接字而中断。实际运行的本机基线得到 154 项通过。[首次日志](baseline.log)
- 构建最初受到 Avalonia 的编译日志写入限制；实际编译还发现三个时间标签的 XAML 格式字符串错误，修复转义后重新构建通过。[首次编译错误](build-rerun.log)、[最终编译](ui-build-verified.log)
- 首轮 UI 检查在点击「取消」时失败。原生确认弹窗挂在窗口的装饰层，修正验收程序的查找范围后通过。截图复查还发现转场未结束和干扰开关不清晰，最终等待转场完成并重新验证了可见开关的点击。[首次 UI 错误](ui-1/error.txt)、[最终画面](verified/ready.png)
- 新应用包第一次深度签名检查发现替换的主程序集缺少签名，给程序集和应用分别签名后验证通过。[初次签名记录](mac-sign.log)、[最终签名记录](signature.log)
