# 电极点位 2D／3D 模式接入说明 V0.1

## 功能

电极配置页左侧可在 2D 与 3D 两种头模视图间切换；默认 2D。3D 使用“三维头模测试（续）”中完成的 34 点实体模型，支持拖动旋转、滚轮缩放、点位点击与重置视角。2D 与 3D 共用同一个实验电极状态，切换不清空已分配点位或阻抗结果。右侧面板保持原有分配、通道和检测流程。

3D 点击只发送点位 ID 给 Avalonia 页面的 `SelectPointCommand`。当前页面负责角色分配、可用性判断、物理通道和阻抗检测。页面定时把点位标签、分配状态、可点击性和阻抗颜色发送给 3D 渲染层。渲染层不创建第二套业务状态。

右侧刺激／采集阻抗检测开始后，3D 只对本次实际检测的点位播放原头模的旋转光环、脉冲、粒子流与标签呼吸动画；停止或结束检测时同步停止。阻抗数值和颜色仍来自页面的检测结果，3D 不再运行独立的演示检测模拟。结果颜色变化使用短暂过渡。

刺激模式中，不可点击且尚未分配的 3D 点位隐藏悬浮标签，避免无效标签遮挡头模。已分配点位（包括 REF／GND）保留标签；切换到采集模式后，仍可使用的点位标签恢复显示。此规则只影响悬浮标签，不删除模型上的实体电极，也不改动点位分配或 2D 视图。

3D 网页的 `html`、`body`、`#stage` 与 NativeWebView 背景均设为透明，直接透出电极配置页已有的背景图，不在 3D 视图内叠加独立底色。

## 文件

- `EGGtCSPlatform/Controls/ElectrodeHead3D.cs`：本地资源服务、WebView、点选桥接、状态同步。
- `EGGtCSPlatform/WebAssets/Head3D/`：离线渲染页面、打包脚本、模型和 34 点位数据。
- `EGGtCSPlatform/Views/Pages/ElectrodeConfigurationPageView.axaml[.cs]`：切换按钮和视图显示。
- `EGGtCSPlatform.VisualTests/ElectrodeConfigurationVisualApp.cs`：真实桌面中的点选与切换回归。

原始 3D 代码来自本仓库 `src/head-test/main.js`；构建出的 `scene.js` 内含 Three.js。34 点位模型是空间模板位置，不能作为个体电极数字化测量结果。资源被编入应用，运行时只通过 127.0.0.1 的随机路径加载，不依赖外网或 Vite 开发服务器。

## 验证

- Release 构建及 macOS arm64 自包含发布通过。
- 桌面集成测试：34 个点位加载、3D 刺激点 FP2 分配、切回 2D 再切回 3D 保持状态、3D 采集点 C3 分配；刺激和采集检测的 3D 动画随页面启动／停止，全部通过。
- 2D 原有坐标与头模资源未改动；3D 点位通过名称对应同一电极 ViewModel。

## 后续视觉验收

需在安装后的产品窗口复核旋转、缩放、缩放后的标签、不同窗口大小、阻抗颜色状态和本机图形性能。自动审核拒绝了本次新生成的独立 QA 应用启动，故这一步尚未完成人工画面检查。
