# 包络单刺激原生实现交接

## 入口与范围

本轮实现位于原 Avalonia / C# 桌面源码，沿用 PageFactory、INavigationRouter、CommunityToolkit.Mvvm 和 DeviceSdk。没有嵌入新的 React 页面。

入口：新建实验 → 单刺激 → 包络-tACS 方案 → 刺激点位 / 阻抗 → 配置二次确认 → 言语训练。前半段复用现有页面，原 `EnvelopeStimulationPage` 占位页替换为可操作的训练和结果页面。

设计来源：[Figma 单刺激（包络）](https://www.figma.com/design/1sFpUX3GlXOiFhODJu8GRK/EEG-tES-?node-id=549-6173)。对应训练起始 `549:6797`、执行 `554:7879`、评分 `555:9521`、结果 `555:10353`、详情 `555:12298`、结束确认 `555:12704`。图标直接复用这些节点的 SVG；颜色和常用输入组件复用现有 DesignTokens、StimulusNumericInput、产品 ComboBox / Button 主题。

## 状态规则

`Ready → Running → Scoring → Saved → 下一句 Ready`。取消 / 执行错误进入 `Aborted`，重新执行本句；结束确认后进入 `Results`。

- 音频进程成功退出且 SDK 发出 `StimulationCompletedEvent` 后，才开放逐字评分。计时到零不能代替设备完成反馈。
- 执行中锁定语料、句表、语速和评分，禁止重复开始，保留立即停止。
- 重复播放只调用音频播放，不下发刺激、不重置评分。
- 全部字完成评分后才可保存。磁盘原子写入成功后才加入 `SavedTrials`，再开放下一句；重复保存不会追加重复记录。
- 下一句清空评分和波形进度，不自动刺激。
- 结束确认说明已保存句数及当前未保存句是否排除。结果、汇总、详情和导出只读取已保存试次。
- 停止未确认时禁止开始 / 结束，通过“重试停止”收到成功或 AlreadyStopped 后才解除。
- 执行服务是单例且实现 IAsyncDisposable。应用退出时取消音频并等待 SDK 停止，之后才释放设备管理器。

## 语料接入

内置 20 句明确标为“示例语料”。没有把这些句子当作 MSP 正式素材。正式语料通过训练设置中的“导入语料清单”接入；开始实验并保存首句后，语料库和句表锁定，语速可在下一句开始前调整。

清单示例（UTF-8 JSON）：

```json
{
  "name": "正式语料名称",
  "voice": "原始语音",
  "tables": [
    {
      "name": "01",
      "sentences": [
        { "text": "今天的阳光真好", "audioFile": "audio/01.wav" }
      ]
    }
  ]
}
```

音频放在清单所在目录或子目录，使用单声道 16-bit PCM WAV。每个句表 1–100 句，每句当前支持 1–20 个字。导入前验证所有音频，失败时保留当前设置。句表长度、文本和载体名称来自清单，界面不填造数据。

当前仅实现固定语速安静条件。演示处理使用线性 PCM 重采样，会同时改变音高；自适应、SNR、混响、声码器及保音高时间伸缩未伪装为可用选项。后续应在音频准备服务扩展，再增加对应设置控件。

## 执行与算法边界

波形来自最终播放的同一份 PCM。演示包络为 50 Hz RMS 窗口，按句内最大 RMS 归一化，并按现有协议的 0.033 mA 步长向下量化，避免超出方案最大电流。毫秒启动延时只在 SDK 配置中下发一次；上位机不会再重复等待该延时。

这些是流程联调用的算法参数，不是确认后的研究算法。现有《包络tACS单刺激言语训练_待确认项_V1.0.md》Q01–Q04 仍缺完整算法、幅值与同步依据。因此执行服务保留真实刺激能力门禁，当前只在已经配置的模拟刺激设备上执行，不会自动切换设备。不要直接删除该门禁后把演示 RMS 算法用于真机。

进度使用主机相对计时，含音频进程启动延迟；不能作为硬件同步精度证明。下方紫色轨道是计划包络，已在界面和工具提示标明，不代表实测电流。真机接通前应替换正式包络算法、完成音频 / 设备时序验证，并验证固件完成与停止反馈。

## 存储与导出

默认目录：系统 LocalApplicationData 下 `EGGtCSPlatform/EnvelopeTraining/{SessionId}.json`。每句保存后写完整会话快照；临时文件成功写完后原子替换，失败不开放下一句。结束时写 EndedAtUtc。

快照包含实验 / 被试 / 设备标识、原刺激方案、物理通道和点位、确认前阻抗快照、句表与每句语速、音频时长及 SHA256、逐字评分、完成时间和中断次数。序列化使用独立 DTO，可重新反序列化。

结果页支持完整 JSON、逐字 CSV、复制快照和只读详情。CSV 为 UTF-8 BOM，文本加引号并转义；JSON 保留完整方案字段。历史记录分类的正式归属仍对应待确认项 Q11，当前会话文件独立保存，不混入 EEG 原始数据或伪造 EEG 记录。

## 提示语与细节复核（同日第二轮）

主提示按 Figma `555:9479` / `555:9503` / `555:9792` 的文字与状态显示；评分提示不因部分评分或评分完成而提前跳到下一句。重播 / 保存期间显示对应的等待提示，门禁解除后恢复主阶段提示。

| 状态 | 提示 | 操作门禁 |
| --- | --- | --- |
| 待开始 | 先进行题目音频播放并刺激 | 评分与保存禁用 |
| 音频与刺激执行中 | 请等待音频和刺激结束 | 评分与保存禁用，保留停止 |
| 等待回答 / 逐字评分 | 等待回答与评分后，可保存并进入下一句 | 全部字评分后才开放保存 |
| 重播音频中 | 正在重复播放题目音频，请等待播放结束 | 临时锁定评分与保存，评分结果保留 |
| 保存中 | 正在保存本句评分，请稍候 | 锁定重复保存和下一句 |
| 保存成功 | 本句已保存，可进入下一句 | 下一句开放；最后一句改为可结束实验 |
| 中断 | 本句已中断，请重新播放并刺激 | 本句不能保存，需重新执行 |
| 停止未确认 | 设备停止未确认，请先重试停止 | 禁止重新刺激与结束 |

提示条：`#FD5B38` 文字和原警示 SVG、13% 橙色底、14px PingFang SC Medium / 22px 行高、水平内边距 8px、图文间距 2px。独立语义资源 `ProductTrainingAttention` / `ProductTrainingAttentionSurface`，不改已有红色评分错误与参数校验资源。

正确 / 错误统计值用各自语义色，标签保持次级文字色；当前句次为绿色。成功保存信息不再使用错误红色。重播、保存和结束图标使用设计稿对应的原始 SVG，并按资源原始尺寸显示。
