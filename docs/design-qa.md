## 已验证交互

- 被试 ID 为空时出现输入错误；填写后可进入电极配置。
- 返回新建实验页时保留已输入内容。
- `.expp` 文件选择器已连接原生本地文件输入。
- 采集电极默认选中；刺激电极模式可选择 A/C 极性。
- 点位选择会同步点位样式、已选标签和阻抗列表。
- 同一点位切换角色时替换原角色，不产生重复项。
- Pz 刺激点与 P4 采集点组合会触发距离告警。
- 阻抗复检保留定时检查和数值更新行为。
- 验收时未观察到浏览器控制台错误或框架错误遮罩。

## 当时结论

在请求的非 3D 模型 UI 范围内，没有遗留 P0、P1 或 P2 问题，旧项目记录的最终结果为 `passed`。
