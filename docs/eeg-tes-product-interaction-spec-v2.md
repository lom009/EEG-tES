# EEG-tES 脑机实验系统产品交互说明 V2.0

> 文档状态：交互基线草案  
> 更新日期：2026-08-18  
> 适用范围：当前 EEG-tES 上位机产品设计与交互原型  
> 说明：本文以最新页面、最新业务讨论和已确认规则为准；旧版文档仅作为历史资料，不用于判断当前流程。

## 1. 产品定位与边界

EEG-tES 是面向实验操作者的脑电采集与经颅电刺激联合实验上位机。系统负责患者与实验建档、刺激方案配置、电极与物理通道映射、阻抗检测、实验运行监控、数据记录及结果导出。

当前产品服务两个核心角色：

- **操作者**：登录系统、连接下位机、创建实验、配置刺激与采集、执行检测、启动或停止实验、查看和导出结果。
- **被实验患者**：接受耐受度测试、脑电采集和刺激；患者本人通常不直接操作系统，但其身份、耐受记录和每次实验记录必须贯穿全流程。

当前原型用于验证产品流程与交互规则，不代表已经达到医疗器械或临床使用标准。真实硬件协议、参数安全范围和临床方案需要由硬件、算法、医学及法规团队最终确认。

## 3. 端到端主流程

```text
登录
  ↓
首页并检测下位机连接
  ├─ 未连接：弹出“串口与下位机”配置，完成连接后继续
  └─ 已连接：开放实验与耐受度测试
  ↓
患者耐受度测试（首次或需要重新测试时，在首页独立完成）
  ↓
新建实验：患者与实验信息
  ↓ 保存 Experiment Draft
刺激参数配置：范式、阵列、参数、通道电流、波形预览
  ↓ 方案校验通过
电极配置与检测：刺激点位、采集点位、物理通道、阻抗
  ↓ 刺激/采集阻抗均通过
实验配置确认
  ↓ 二次确认
实验时序与运行：手动模式或自动模式
  ↓
实验结果：记录、波形、异常、导出
  ↓
历史记录：查看结果或复制配置创建新实验
```

## 4. 全局状态与准入门禁

### 4.1 下位机连接门禁

- 登录成功进入首页后，系统立即检测下位机连接状态。
- 未连接时自动弹出连接窗口；开始实验和耐受度测试不可直接进入。
- 历史记录和既有实验结果属于本地/服务端数据浏览能力，可以在设备离线时查看。
- 页面顶部持续展示下位机、采集设备及通信状态，不能仅靠颜色表达。

### 4.2 实验草稿门禁

- 新建实验页面提交后生成独立的 `Experiment Draft`。
- 草稿至少绑定实验 ID、患者 ID、创建时间和操作者。
- 刺激方案校验通过前，不允许进入电极配置。
- 修改刺激范式、阵列、关键参数或刺激点位后，旧的刺激阻抗结果立即失效。
- 修改采集点位、参考电极、地电极或采样配置后，旧的采集阻抗结果立即失效。

### 4.3 耐受度记录门禁

- 耐受度测试从实验内部移至首页，作为患者级记录独立管理。
- 新实验引用该患者最近一次适用的已完成耐受度记录。
- 电极配置页不再重复执行耐受度测试。
- 耐受记录有效期暂不做自动判断；文档保留未来规则，当前由操作者确认是否适用。

## 5. 登录页

### 5.1 页面目标

验证操作者身份，并建立本次系统使用会话。

### 5.2 页面字段与操作

- 账号：必填，当前页面提示手机号；后续可根据账号体系扩展工号或邮箱。
- 密码：必填，默认隐藏，可提供显示/隐藏能力。
- 记住密码：仅在安全策略允许时保存凭据。
- 忘记密码：进入找回流程。
- 登录：提交账号和密码。

### 5.3 交互规则

- 账号或密码为空时，登录按钮可保持可点击，但提交后必须就近提示缺失字段；也可在确认设计规范后采用禁用按钮方案，两种方式不可混用。
- 登录中显示加载状态并防止重复提交。
- 认证失败保留账号、清空密码，并显示可理解的错误信息。
- 登录成功进入首页，随后立即触发下位机连接检测。

## 6. 首页

### 6.1 首页入口

首页包含四个主要业务入口：

1. **开始实验**：创建并配置新的脑机实验。
2. **实验记录**：查看历史实验、运行轮次和结果。
3. **串口与下位机**：查看或修改设备连接。
4. **耐受度测试**：执行患者级耐受测试并查询历史记录。

### 6.2 进入首页时的设备检测

- 页面加载后自动读取当前连接状态。
- 已连接：卡片及顶部状态显示“已连接”，允许开始实验和耐受度测试。
- 未连接：自动打开“串口与下位机”弹窗，并提示“请先连接设备”。
- 操作者关闭弹窗后仍可浏览历史记录，但点击“开始实验”或“耐受度测试”时再次触发连接门禁。

### 6.3 串口与下位机弹窗

字段包括：

- 设备 IP；
- 本机端口；
- 设备端口；
- 设备选择；
- 搜索设备。

交互规则：

- 点击“搜索设备”进入搜索状态，并显示发现的设备或空状态。
- 选择设备后填充可识别的连接信息。
- 点击“保存”先校验 IP、端口和设备，再发起连接。
- 连接成功关闭弹窗并刷新全局连接状态。
- 连接失败保留输入，显示具体失败原因，并允许重试。
- 点击“取消”不保存本次修改；若系统仍未连接，实验相关入口继续受限。

## 7. 首页耐受度测试

### 7.1 信息结构

耐受度模块包含两个 Tab：

- **耐受度测试**：选择患者并执行新的耐受度测试。
- **历史记录**：查看所有患者的耐受度结果。

### 7.2 耐受记录字段

- 患者 ID；
- 最终耐受值及单位；
- 测试时间；
- 测试人；
- 采用的刺激范式或测试协议；
- 主观反馈；
- 备注；
- 完成/中止状态。

### 7.3 业务规则

- 测试前必须确认下位机已连接。
- 测试值只能按协议允许的步长逐级变化，达到上限后不可继续增加。
- 操作者记录患者反馈后确认最终耐受阈值。
- 中止测试也要生成记录，但不能作为新实验的已完成耐受结果。
- 有效期、跨范式复用和复测周期暂列为待定义规则。

## 8. 新建实验

### 8.1 页面目标

建立一次独立实验的身份和上下文。新建实验完成后，下一步不是电极配置，而是进入**刺激参数配置**。

### 8.2 页面内容

- 新建实验 / 历史记录 Tab；
- 系统生成的实验 ID；
- 创建日期与时间；
- 患者 ID：必填；
- 备注：选填；
- 导入历史配置；
- 导入实验参数包 `.expp`；
- 主按钮“进入刺激方案配置”。

### 8.3 交互规则

- 实验 ID 在创建页面时生成，保存草稿后保持不变。
- 患者 ID 必须存在或完成临时建档；不存在时应提示创建患者信息。
- “导入历史配置”只复用方案、参数和点位模板，不继承阻抗结果、准入结果或运行结果。
- 导入 `.expp` 后展示解析结果、协议版本、兼容性和冲突项，不能静默覆盖当前内容。
- 点击“进入刺激方案配置”时：校验患者 ID → 创建 Experiment Draft → 绑定适用耐受记录 → 进入刺激参数配置页。
- 若当前患者没有可引用的已完成耐受记录，系统给出明确提示；是否允许继续由最终业务门禁策略决定。
