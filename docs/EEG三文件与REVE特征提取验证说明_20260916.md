## 1. 本次完成了什么

已完成“EDF 数据读取 → CSV 与参数包核对 → 按采集段预处理 → 官方电极坐标匹配 → REVE 本地推理”的完整技术链路。

从两段共76秒的模拟采集数据中，选取6个10秒窗口，每个窗口包含8个通道。模型为每个窗口生成512维特征向量，共得到形状为 `[6, 512]` 的窗口级表征。所有输出为有限值；同一首窗口重复推理的最大数值差为0。

这说明本次导出格式能够接入模型。当前产物是脑电特征表示，尚不是脑状态判断、信号质量评分、康复指标或疗效结论。本次没有训练任务分类器，也没有验证真实被试上的准确性。

### 2.1 EDF：保存“采到了什么”

- 格式为EDF+D，即允许记录在时间上不连续的EDF+文件。
- 共9个信号项：8个EEG通道和1个 `EDF Annotations` 注释项。注释项不能当成第9个EEG通道输入模型。
- 原始采样率500 Hz，物理单位μV；每通道38,000个采样点。
- 有效采集总时长76秒，覆盖的实验时间范围为0至111秒。
- 通道顺序为：`FC6、C6、CP4、CP5、CP6、T7、P3、P4`。
- 文件声明的数据长度与实际长度一致；各通道非全零，也不是完全相同的拷贝。
- EDF的数字值需要根据每个通道的digital/physical min、max转换为物理电压，不能把16位整数直接作为μV使用。

头部预滤波字段为 `None`，但这不能独立证明设备端完全未进行信号处理。

### 2.2 CSV：保存“可直接查看的采样表”

CSV包含 `TimestampUtc、ElapsedSeconds、Cycle、Stage`，以及与EDF一致的8个通道列。此次CSV是采样数据表，不是故障日志。

共38,000行，全部标记为 `Acquisition`；Cycle 1和2各19,000行。与EDF逐点核对后，时间轴一致，各通道最大绝对数值差不超过约0.0014681 μV。这与EDF量化及标定精度造成的微小差异相容。

CSV本身没有明确的通道单位字段；本次结合对应EDF按μV理解。EXPP中的通道排列与CSV/EDF不同，程序按通道名称关联，而不是按配置数组位置关联。

## 3. 时间轴与刺激空窗的理解

| 实验相对时间 | 内容 | 证据 |
|---|---|---|
| 0–38秒 | 第一段采集 | EDF采样及 `Acquisition cycle 1` 注释 |
| 38–39秒 | 配置的消隐阶段 | 根据EXPP推断 |
| 39–72秒 | 配置的刺激阶段 | 根据EXPP推断 |
| 72–73秒 | 配置的恢复阶段 | 根据EXPP推断 |
| 73–111秒 | 第二段采集 | EDF采样及 `Acquisition cycle 2` 注释 |

区间采用左闭右开理解，例如第一段最后一个采样时刻为37.998秒。

用户已确认刺激期不采集EEG。文件实际存在35秒无采样区间，与“消隐1秒＋刺激33秒＋恢复1秒”的配置总时长吻合。三个子阶段的边界由配置推断，EDF中没有各自的实测开始/结束事件。

处理时保留空窗；不补零、不插值、不将两段拼成无间隔连续信号，滤波和切窗均不跨空窗。

EXPP的 `cycleCount=1`，而采样数据出现Cycle 1、2。该业务命名尚未确认，因此统一称“采集段1、采集段2”，不推断为两次刺激，也不直接赋予康复评估中的Pre/Post标签。

## 4. REVE 的特征编码是什么意思

一个窗口在重采样后包含8通道×2000点，即16,000个电压数值。REVE将这些电压与电极位置共同输入编码器，生成学习得到的数值表示。

传统频段分析事先规定指标，例如α功率、β功率或通道相关性，每个数值都有明确计算定义。REVE的512维表征由模型学习形成，通常不能给每一维赋予“α波”“注意力”等固定名称。多个维度共同表达模式，同一维度也可能参与表达不同模式。

因此，“编码”是将信号转换为后续算法可使用的特征，不是自动生成文字解读。特征可能包含时序、频率、空间和干扰等信息；本次没有验证具体维度编码了什么。

后续可用这些表征进行相似度比较、聚类或训练有标签的任务模型。距离变化本身只表示模型表征不同，不能直接解释为状态改善。

## 5. 本次实际处理步骤

1. 校验EDF头部、数据长度、采样率、单位、时间注释及数字到物理电压标定。
2. 根据EDF+D时间戳识别两段采集，逐点核对CSV，按通道名称关联EXPP配置。
3. 每段独立从500 Hz重采样至200 Hz，使用SciPy `resample_poly`，本例倍率为2/5，Kaiser抗混叠FIR及line边界填充。
4. 保留μV及输入通道顺序。本次没有额外带通、陷波、幅值标准化或软件重参考。
5. 每段按10秒非重叠窗口切分，各取3个完整窗口；末尾8秒保留在整段数组中，但未进入本次固定窗口推理。
6. 在官方位置表中精确查找8个通道，随后实际加载位置库权重，验证生成的坐标与已保存坐标一致。
7. 固定版本本地加载REVE，使用CPU、float32、eval模式和inference mode推理；通过模型的attention pooling汇聚窗口特征。
8. 检查输出是否含NaN/Inf，并对首窗口重复推理核对一致性。

窗口与原始时间的对应关系：

| 特征行（从0计） | 采集段 | 时间范围 |
|---:|---:|---|
| 0 | 1 | 0–10秒 |
| 1 | 1 | 10–20秒 |
| 2 | 1 | 20–30秒 |
| 3 | 2 | 73–83秒 |
| 4 | 2 | 83–93秒 |
| 5 | 2 | 93–103秒 |

本次模型覆盖60秒数据；有效采集总时长为76秒，二者不同。30–38秒和103–111秒没有丢失，保存在适配数据包的完整分段中。

## 6. 幅值与参考方式的处理依据

官方模型说明要求200 Hz的 `[batch, channels, time_points]` 输入及对应电极坐标。官方PhysioNet预处理示例输出μV，同时使用平均参考、0.3 Hz高通和60 Hz陷波；这些是该数据集的方案，不能直接当作所有设备的统一要求。

本次审阅的模型forward入口没有显式对原始输入做z-score。因此当前技术验证保留μV，不擅自增加平均参考或归一化。这不代表已经确认了适用于真实业务的最优预处理。

FCz/AFz是EXPP声明的参考/地电极。设备导出前是否已重参考、滤波或幅值归一化仍待研发确认。模拟数据可以继续用于链路测试，真实任务验证前需把这些处理约定固定下来。

局部特征中的11来自长度200点、重叠20点的内部时间切片，步长180点。这与外部10秒窗口是两层不同切分。窗口级512维向量通过attention pooling汇聚通道与时间片特征，适合后续比较，但不保留同等程度的时空细节。

耗时仅针对本机本次CPU运行，包含首轮开销，不包含模型下载、启动加载或完整文件预处理，不是实时系统性能承诺。重复性只在本次环境对首窗口验证，不能据此保证所有设备和软件版本逐位一致。

本次权重已直接下载成功，没有要求用户提供Token；此前“必须先申请权限”的表述不能作为当前实际访问状态的结论。后续使用仍应以官方当前仓库访问状态及许可证为准。

## 9. 已证明与尚未证明的事情

已经证明：这份模拟导出文件可解析；CSV与EDF一致性较好；不连续采集时间可以保留；8个通道能匹配官方坐标；固定REVE模型能生成数值有效且本次重复一致的特征。

尚未证明：真实脑电质量是否合格；特征对应何种生理含义；能否识别具体任务或异常；是否优于传统频段指标；是否能判断刺激效果或康复变化。本次也未计算频段功率、进行分类训练或产生前后变化显著性结论。

产品目前没有接入康复指标，并不妨碍技术验证；下一阶段应根据现有EEG产品明确任务，再选择数据和标签。若当前需求只是波形与频段功率展示，可先用传统信号处理实现；REVE的增量价值需另行比较。
