# EEG-tES PRD 待确认项清单

关联文档：[EEG-tES 上位机产品需求文档（PRD）](./EEG-tES_产品逻辑PRD_V1.0.md)

版本：V1.3.0
日期：2026-07-29

> 本清单用于软硬件联合评审。未确认项不得由前端原型值代替真实设备或研究规则。

## 一、设备与通信

### 1. 目标设备

- 设备型号、序列号和固件版本；
- 刺激通道、EEG 通道及共享规则；
- 支持的刺激范式、阵列和同步 EEG+tES 能力；
- 串口默认波特率、握手、心跳、重连和固件升级策略；
- 通信断开时下位机自身的安全行为。

### 2. Capability schema

- 五类范式的字段 schema；
- 参数单位、最小值、最大值、精度和步长；
- 阵列所需通道数和通道分配能力；
- 阻抗、滤波、急停和运行恢复能力；
- capability 与固件版本的兼容策略。

## 二、刺激范式与阵列

### 3. tDCS

- 双通道、HD、多靶点分别支持哪些参数；
- HD 是 4 通道还是 5 通道；
- 中心电流、回流分配和电流平衡规则；
- 多靶点总电流和极性组合上限。
- 双通道使用恰好 1 个阳极和 1 个阴极；需确认设备协议中的物理通道映射和电流符号约定。

### 4. tACS

- 幅值口径使用峰值、峰峰值还是 RMS；
- 频率、相位和直流偏置能力；
- HD/多靶点是否允许各通道独立幅值和相位；
- 通道同步精度。
- 双通道正式使用 ChA/ChB、0°/180°还是其他设备通道命名；
- 多通道瞬时电流平衡的计算和下发口径。

### 5. tRNS

- 频带范围；
- 噪声分布；
- 随机种子是否可控、是否需要保存；
- HD/多靶点支持情况。
- 双通道是否使用 ChA/ChB，以及回流通道是否由设备自动生成。

### 6. tPCS

- 脉冲波形；
- 脉宽或占空比；
- 单相/双相及极性；
- 频率、相位和多通道同步规则。

### 7. Sham

- 直流和交流模拟算法；
- 缓升、短刺激、等待和尾段刺激规则；
- 与真实方案的绑定方式；
- 双盲信息隐藏和解盲记录。
- 是否禁止独立修改阵列和点位，以及来源方案变更后的自动失效规则。

## 三、患者耐受度与阻抗

### 8. 阻抗

- 刺激和采集阻抗测量方法、原始单位及分级阈值；
- 是否支持逐通道进度与中途停止；
- 停止检测后部分结果如何处理；
- 运行中是否支持连续或间歇监测；
- 结果新鲜度和必须复测的条件。

### 9. 耐受测试

- `2%` 增减的计算基数；
- 各范式按钮锁定时长；
- 各范式最大测试电流/幅值；
- 患者反馈量表和通过标准；
- 首页测试过程是否需要独立的测试阻抗或接触状态门禁；
- 耐受记录的有效期和复测周期；
- 患者与刺激范式的匹配粒度；
- 跨设备、固件或协议版本是否允许复用；
- 不耐受或中止后如何保存记录及允许的后续操作。

## 四、采集与时序

### 10. EEG 采集

- 500 Hz 是否是固定值、默认值还是模板值；
- 可用采样率范围；
- 参考、地、EOG/ECG/EXT 的硬件规则；
- 高通、低通和陷波默认值；
- 高通、低通和陷波是否都允许独立开关，以及运行中修改的生效和记录规则；
- 原始数据与显示滤波数据的保存方式；
- EEG、刺激和 marker 的时钟同步。

### 11. 手动模式

- 采集结束后何时允许开始刺激；
- 急停后是否允许继续当前阶段；
- 继续前必须复核哪些阻抗和设备状态；
- 继续是复用 Run ID 还是产生子段记录。

### 12. 自动模式

- 循环次数上限；
- 循环间隔；
- 每轮是否重新检查阻抗；
- 急停后从头重跑的下位机复位要求；
- 正常完成后“再进行一次”是否复用全部运行配置，以及是否需要再次确认阻抗；
- 新 Run 的继承和审计字段。

## 五、患者、数据与历史

### 13. 患者数据

- 正式称谓使用患者、被试还是受试者；
- 患者数据来源；
- 必填身份和人口统计字段；
- 临时录入权限；
- 脱敏、访问、导出和保存周期；
- 是否记录伦理项目和知情同意。

### 14. 历史配置复用

- 允许复用哪些阈值和时序；
- 是否保留历史来源链；
- 跨设备、跨固件时的转换规则；
- 不兼容历史配置是否允许保存为不可运行草稿；
- 历史患者是否默认保留或必须重新选择。

### 15. 实验数据和导出

- EEG 主文件格式；
- 配置、阻抗、耐受和事件日志格式；
- 文件命名和校验值；
- 本地/服务器存储位置；
- 写入失败和重新导出策略；
- 数据字典和格式版本。

## 六、当前产品假设

1. 只有操作者和被实验的患者两个核心角色；
2. 页面顺序为：首页 → 患者与实验 → 刺激方案 → 电极配置与检测 → 时序/运行/结果 → 历史；
3. 刺激方案先于刺激和采集电极配置；
4. P0 范式为 tDCS、tACS、tRNS、tPCS、Sham，TI 暂不纳入；
5. HD 是阵列/通道模式而不是独立刺激范式；
6. 只有 tDCS 双通道默认使用恰好 1 个阳极和 1 个阴极；tACS、零均值 tRNS 和双相 tPCS 使用通道/相位角色；
7. Sham 继承来源真实方案的阵列、点位和角色，不允许独立配置；
8. 保留静态头模和 20 点共享坐标；
9. 患者耐受度测试位于首页，生成患者级独立记录；页面 3 不再重复执行耐受测试；
10. 本版本暂不实现耐受记录有效期自动失效；
11. 联合实验默认刺激阻抗和采集阻抗均通过后才允许进入运行前摘要；
12. 历史配置可复用，但物理检测结果不可复用为本次通过状态；
13. 手动模式的采集和刺激分别显式开始；
14. 自动模式急停后创建新 Run 并从头执行；
15. 正常完成后可以在同一 Experiment 下新建 Run 再次运行；
16. 时长支持 `s / min`，内部统一换算后执行；
17. 真实安全阈值不写死，由 capability、固件、范式规则和研究协议共同决定。

## 七、推荐评审顺序

```text
设备与 capability
→ 五类刺激范式
→ 阵列和硬件通道模型
→ 参数范围与安全规则
→ 首页患者耐受度与耐受记录
→ 刺激/采集阻抗
→ EEG 采集与同步
→ 手动/自动运行
→ 患者、历史和导出
```

每项结论需记录：负责人、依据、适用设备、固件版本、生效日期和变更影响。
