## 三、已确定而无需再次讨论的边界

- 本版单刺激，无EEG、录音、转写、时间对齐或自动评分。
- 准备与执行分开；试次状态控制可用操作。
- 六阶段为训练设置、本句准备、播放／刺激、患者回答、人工评分、完成实验；主按钮随阶段变化。
- 下一句返回准备阶段并继承设置，不自动刺激；页签切换只切换视图，不推进流程。
- 刺激时长跟随本句最终音频，修改音频条件后重新准备；联合执行的具体时序仍待确认。
- 保留刺激点位和阻抗，不要求采集点位或采集阻抗。
- 实验页左侧刺激监控/训练页面，右侧统一监控与控制。
- 没有真实反馈则波形标为计划预览。
- 人工评分初始未评分；保存成功才下一句。
- 重播音频不自动刺激；重新执行生成新试次。
- 不新增患者独立视图；后续需求另议。
