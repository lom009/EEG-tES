# EEG-tES 产品交互说明

## 1. 文档目的

本文档描述 EEG-tES 前端原型的页面结构、核心状态、交互规则和验收标准，用于产品、设计、研发和测试协作。

当前版本是前端交互原型：使用模拟实验数据和定时器演示流程，不连接真实 EEG/tES 设备，不构成医疗诊断或治疗软件。

## 2. 核心用户与目标

- **实验操作人员**：创建实验、配置电极、完成阻抗检查并运行实验。
- **研究人员**：查看历史实验记录、配置刺激方式并导出实验数据。
- **测试与演示人员**：通过“测试点位全通过”快速构造可进入实验阶段的演示状态。

产品核心目标是让操作人员按照固定顺序完成：

`新建实验 → 电极配置 → 采集阻抗检查 → 刺激配置与耐受测试 → 刺激阻抗检查 → 运行实验 → 结束与导出`

## 3. 页面与导航

### 3.1 新建实验

- 默认展示“新建实验”页签。
- 被试 ID 为必填项；缺失时不能进入电极配置，并显示校验状态。
- 备注为非必填项。
- 支持选择本地 `.expp` 文件。
- 点击“下一步：电极配置”会创建一次全新的实验：清空旧实验点位、阻抗和刺激流程状态，再进入电极配置。
- 新实验的 20 个点位全部为白色未分配状态。

### 3.2 历史记录

- “历史记录”页签展示时间、设备/实验 ID、被试、刺激类型、操作人员和查看操作。
- 当前为演示数据，查看按钮只表达设计状态，不连接后端记录详情。

### 3.3 电极配置与阻抗检查

- 页面顶部可以返回项目启动页。
- 采集与刺激使用同一个头模、同一尺寸、同一位置和同一套 20 点坐标。
- 页面右上“下一步：进行实验”只有在已分配点位全部获得绿色“优”结果时可用。
- “测试点位全通过”是演示辅助开关，只生成通过展示，不覆盖真实点位分配数据。

### 3.4 实验运行

- 顶部支持手动模式和自动模式切换。
- “返回电极配置”位于内容区左上状态行首位；返回时保留当前实验的电极配置。
- 左侧展示实时信号模拟波形和时序概览。
- 右侧展示运行监控、刺激参数、阶段时长、阶段状态和操作按钮。

## 4. 电极点位规则

### 4.1 共享布局

- 所有电极页面必须使用同一个头模视觉锚点。
- 20 个点位坐标在采集、刺激、未检测、已检测和重新编辑状态下均不得移动。
- 切换采集/刺激只改变角色、标签、颜色和右侧面板内容。

### 4.2 点位状态

| 状态 | 视觉 | 点击行为 |
| --- | --- | --- |
| 未分配 | 白底默认样式 | 分配为当前角色，进入蓝色选中态 |
| 采集已选未检测 | 蓝色选中 | 可再次点击取消或切换角色 |
| 刺激已选未检测 | 蓝色选中并显示 `·A` / `·C` | 可再次点击取消、切换角色或切换极性 |
| 已检测 | 按阻抗语义显示绿/蓝/橙/红 | 仍可点击；只重置当前点位为新选未检测态 |
| 隐藏查看 | 已分配角色降低到 30% 透明度 | 不修改分配、极性和阻抗结果 |

点击任意一个点位只能改变该点位，其他点位的角色、测量结果和视觉状态保持不变。

### 4.3 阻抗语义

| 阻抗范围 | 结果 | 颜色语义 |
| --- | --- | --- |
| `≤110 kΩ` | 优 | 绿色 |
| `10～20 kΩ` | 良 | 蓝色 |
| `20～30 kΩ` | 中 | 橙色 |
| `30～40 kΩ` | 差 | 橙红色 |
| `>40 kΩ` | 不良 | 红色 |

当前原型使用固定模拟值，颜色规则用于交互演示，不代表真实设备阈值实现。

## 5. 采集电极流程

1. 切换到“采集电极”。
2. 点击白色点位，将其分配为采集角色并显示蓝色选中态。
3. 已选点位同步显示在通道角色标签区。
4. 下发采集配置后执行模拟阻抗检测。
5. 检测完成后，头模点位和右侧阻抗列表同时显示该点位结果。
6. 检测后的点位仍可点击；重新点击只使当前点位回到未检测选中态，并使旧结果失效。

## 6. 刺激电极流程

### 6.1 角色与极性

- 刺激支持阳极 `A` 和阴极 `C`。
- 阴极点位显示为 `点位·C`，阳极显示为 `点位·A`。
- 极性后缀同时出现在头模、标签和阻抗列表。

### 6.2 阻抗检测前置流程

刺激阻抗不能在点位分配后立即出现，必须完成：

1. 点击“确认并下发刺激配置”。
2. 进入居中的两步弹窗，头模和右侧面板保持原位。
3. 第一步配置刺激参数。
4. 第二步配置耐受阈值；可导入历史耐受数据。
5. 确认阈值后开始模拟刺激阻抗检测。
6. 检测完成后，刺激点位保留 `·A` / `·C` 后缀，并在头模和列表中显示语义结果色。

修改任意刺激点位或极性都会使此前刺激阻抗结果失效，并要求重新完成两步流程。

### 6.3 刺激类型

- 支持 `tDCS`、`tACS`、`TI`、`HD`。
- 类型选择使用产品自定义下拉，不使用浏览器原生 `<select>`。
- 波形和参数区域随类型切换。
- tDCS 使用 Figma 原始波形资源；TI/HD 使用各自设计稿内容和本地资源。

## 7. 实验运行状态机

实验包含四个可见阶段：采集、消隐、刺激、恢复；另有待机、刺激待开始、已完成和已急停状态。

### 7.1 手动模式

`待机 → 用户开始采集 → 采集 → 消隐 → 刺激待开始 → 用户开始刺激 → 刺激 → 恢复 → 已完成`

- 采集、消隐、刺激、恢复在达到配置时长后自动结束。
- 手动模式在“刺激待开始”暂停，必须由用户点击刺激阶段的“开始”。
- 运行过程中不显示“进入下一阶段”按钮。

### 7.2 自动模式

`待机 → 用户点击一次开始 → 采集 → 消隐 → 刺激待开始 → 刺激 → 恢复 → 已完成`

- 自动模式只需要一次开始操作。
- 中间阶段不再要求用户点击。
- 刺激循环次数支持输入或点击上下按钮调整，范围为 `1–99` 次。
- 每个循环都会执行完整的采集、消隐、刺激和恢复；达到设定次数后进入完成状态。
- 自动模式启动后循环次数锁定，避免运行中改变既定流程。

### 7.3 阶段状态

- **待执行**：灰色时钟图标。
- **进行中**：绿色状态和旋转载入图标，当前行使用绿色虚线边框。
- **已完成**：绿色完成图标。
- **已中断**：急停后所有未完成阶段显示中断语义。

右上状态环在运行阶段显示绿色中心波形，并旋转“旋转外环”图层。

## 8. 时长输入与单位

### 8.1 可编辑范围

- 采集和刺激阶段可编辑。
- 消隐和恢复阶段为只读状态。
- 采集时长仅在待机状态允许修改，采集开始后锁定。
- 手动模式下，刺激时长在待机和“刺激待开始”状态均可修改；点击刺激“开始”后锁定。
- 自动模式启动后不再开放中途编辑，避免短暂阶段切换改变既定流程。

### 8.2 输入规则

- 最小值：`10 ms`。
- 最大值：`60 s`。
- `ms` 支持整数显示。
- `s` 最多显示三位小数。
- 空值或非数值在失焦时恢复最后一次有效值。
- 低于或高于范围的数值在失焦时自动限制到最小值或最大值。
- 按 Enter 提交，按 Escape 放弃当前草稿并恢复有效值。

### 8.3 单位切换

- 使用自定义 `ms / s` 下拉。
- 切换单位只换算显示，不改变真实时长，例如 `1500 ms` 等于 `1.5 s`。
- 下拉支持外部点击关闭、Escape 关闭、当前项选中状态和键盘焦点提示。

### 8.4 运行行为

- 内部统一按毫秒保存。
- 用户设置的采集和刺激时长直接用于阶段定时器；数值越大，阶段持续越久。
- 底部时序概览同步显示采集和刺激的最新值及单位，但色块宽度保持设计稿固定视觉比例。
- 运行时长从实验第一次开始时累计，在已完成或急停后冻结，重新进入待机时清零。

## 9. 安全与结束操作

### 9.1 紧急停止

- 运行期间始终提供红色“紧急停止刺激”。
- 点击后立即取消当前阶段定时器，状态变为“已急停”，累计运行时长冻结。
- “重新进入待机”会清除当前运行进度，但保留用户配置的采集/刺激时长。

### 9.2 正常完成

- 恢复阶段结束后进入“已完成”。
- 完成状态的四个阶段均显示“已完成”。
- 点击“结束实验”进入导出面板。

### 9.3 导出

- 导出面板展示实验摘要、文件名和导出内容。
- EDF+ 脑电数据和 CSV 故障日志默认勾选。
- 当前“导出数据”按钮只表达原型流程，不写入真实文件。

## 10. 可见性、空状态与禁用状态

- “查看采集电极”和“查看刺激电极”默认均勾选。
- 取消勾选只将对应角色点位降至 30% 透明度，不改变点位数据。
- 尚未检测时，阻抗面板展示“未开始检测”空状态。
- 不满足全绿条件时，“下一步：进行实验”保持禁用。
- 运行阶段中时长输入和单位下拉保持禁用。
- 导入历史数据弹窗关闭时不修改当前耐受阈值；选择记录后才导入并关闭。

## 11. 验收标准

### 11.1 核心链路

- 新建实验后 20 点全部为默认白色。
- 点击一个点位不会影响其他点位。
- 采集与刺激切换不移动头模或点位。
- 刺激阻抗只能在参数和耐受两步确认后生成。
- 全绿后能够进入实验。
- 手动模式在刺激前暂停；自动模式一次启动完成四个阶段。
- 采集/刺激时长输入、边界限制、单位换算和真实等待时间一致。
- 急停、重置、完成、结束、导出和返回电极配置均具有明确状态结果。

### 11.2 技术验收

- 点位状态、重置、自动模式和实验时长回归脚本全部通过。
- Vite 生产构建无错误。
- 本地核心路由返回 HTTP 200。
- 1440 × 900 主视口不遮挡、不溢出；宽屏下信号区自适应，右侧面板保持固定锚点。
- 浏览器控制台目标为零错误、零警告。

## 12. 原型边界

- 无真实设备通信、采样、刺激输出或硬件安全联锁。
- 无后端、鉴权、数据库和历史记录持久化。
- 阻抗、信号波形、运行参数和实验记录均为模拟数据。
- 导出按钮不生成真实 EDF+/CSV 文件。
- 医疗安全阈值、监管要求和设备故障策略需要在产品化阶段单独评审。
