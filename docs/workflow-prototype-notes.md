# EEG-tES 产品流程验证原型

## 原型问题

在不接入真实脑机/刺激器的情况下，验证以下产品逻辑是否能被操作者连续理解并完成：

1. 先定义刺激范式、阵列和参数；
2. 再按阵列角色配置刺激点位，并配置采集点位；
3. 按固定顺序完成刺激阻抗、采集阻抗、耐受测试和最终一致性复核；
4. 锁定不可变协议版本；
5. 分别跑通手动和自动实验；
6. 形成绑定患者、协议版本和 run ID 的结果。

## 入口

启动项目：

```bash
pnpm run dev
```

浏览器打开：

```text
http://127.0.0.1:5173/?screen=workflow-prototype
```

## 原型范围

- 数据全部保存在页面内存中，刷新即清空；
- 阻抗检测、耐受测试和设备事件均为模拟；
- 每个实验阶段被压缩为约 0.85 秒；
- 重点验证步骤顺序、门禁、失效规则和运行状态机；
- 不代表最终 UI、真实设备协议或医疗器械安全实现。

## 关键验证

- `tDCS / tACS / TI` 与阵列拓扑分层，`HD` 不作为刺激范式；
- 刺激点位和采集点位不可静默抢占；
- 刺激阻抗必须先于耐受测试；
- 任何关键配置变化都会使下游检测结果失效；
- 手动模式在刺激前暂停，急停后可复核条件并继续当前流程；
- 自动模式一次跑完，急停后当前 run 中止，重新开始创建新 run 并从头执行；
- 锁定协议版本和每次 run 使用独立 ID。
